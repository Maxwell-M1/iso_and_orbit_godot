# 用語集

> これは[英語の原文](../en/glossary.md)の翻訳です。内容が異なる場合は、英語版が正しいものとします。

このドキュメントとコードで使われている意味での用語です。

| 用語 | 意味 |
|---|---|
| **エージェント半径**（Agent radius） | ナビゲーションメッシュが障害物からどれだけ離れるか：0.5 m。キャラクターのカプセル（0.35 m）より大きいので、経路は角から余裕を保つ |
| **アーム**（Arm） | `CameraArm`：ターゲットから伸びる線の先端でカメラを保持するノード。ホイールでその長さが決まり、障害物で短くなる |
| **カメラ専用ボディ**（Camera-only body） | 物理レイヤー3（`camera`）にあるボディ。カメラアームを止めるが、クリック、ナビゲーション、キャラクターからは無視される |
| **クリック**（Click） | 長押し判定時間内に離された左ボタンの押下。キャラクターはボタンを押した地点まで経路に沿って走る |
| **コヨーテタイム**（Coyote time） | 縁から歩いて落ちた後、まだジャンプが有効な短い時間（0.1秒） |
| **疲労困憊**（Exhausted） | スタミナが尽きた後の状態：スタミナが`recover_ratio`（30%）まで回復するまでダッシュできない |
| **向き**（Facing） | キャラクターが見ている方向で、移動する方向とは区別される。横移動や後退のときに両者は異なる。`NavigationMover.get_facing()` |
| **追従**（Follow） | 走るキャラクターの背後にカメラが自動で回り込むこと。オプションで傾きも徐々に合わせる（`follow_movement`、`follow_pitch`） |
| **進行方向**（Heading） | キャラクターが移動する方向。`NavigationMover.get_heading()` |
| **主人公の外見**（Hero look） | プレイヤーのキャラクターがまとえる10種類のモデルの1つ。設定で番号により選ぶ（`CharacterAppearance`） |
| **長押し**（Hold） | 長押し判定時間より長く押された左ボタン。キャラクターはカーソルを追って走る |
| **長押し判定時間**（Hold delay） | クリックと長押しを区別する時間：0.2秒（`PointClickMoveInput.hold_delay`） |
| **ジャンプバッファ**（Jump buffer） | 着地の少し前に押したジャンプが記憶され、着地時に発動すること（0.12秒） |
| **狙いの保持**（Keeping the aim） | ボタンを押したままカメラが回転する間、システムカーソルを世界と一緒に動かし、カーソルが地面の同じ地点の上にとどまるようにすること（`keep_aim_on_camera_turn`） |
| **落下防止**（Ledge guard） | `LedgeGuard`：0.5 mより高い段差でキャラクターを止めるか、縁に沿って滑らせる |
| **外見**（Look） | 「主人公の外見」を参照 |
| **マーカー**（Marker） | `ClickMarker`：クリックした地点の地面に出るリング |
| **ムーバー**（Mover） | `NavigationMover`：コマンド（`move_to`、`steer`、`stop`）を毎ティック水平方向の速度に変換する。ボディを動かすことはない |
| **ナビゲーションメッシュ**（Navigation mesh） | レベルのレイヤー1のコリジョンからベイクされた歩行可能領域。`world.tscn`に保存されている。経路はこの上で探索される |
| **物理補間**（Physics interpolation） | 物理ティックの間のボディを、ディスプレイのフレームレートで描画すること。デフォルトはオフで、設定でオンにできる |
| **ピッチ、傾き**（Pitch, tilt） | カメラがどれだけ急な角度で見下ろすか。コードでは負の角度、設定では下向きの度数 |
| **その場旋回**（Pivot） | 静止状態（`pivot_speed`（1 m/s）未満）から即座に向きを変えること |
| **場所**（Place） | `PointOfInterest`：プレイヤーが初めて入ったときに「発見：…」を表示するエリア |
| **接近**（Pull-in） | キャラクターを隠す障害物の手前までカメラが寄ること（`pull_in_on_occlusion`） |
| **横移動**（Sidestep） | 右ボタンと組み合わせるキーのモードの1つ：キャラクターは横や後ろへ移動する間も、カメラの向いている方向を向き続ける |
| **シルエット**（Silhouette） | 何かに隠れた部分で、キャラクターを輪郭付きの平坦な形として描いたもの（`OccludedSilhouette`） |
| **ダッシュ**（Sprint） | Shiftを押している間、または切り替えでオンの間、スタミナを消費して速く（×1.5）走ること |
| **スタミナ**（Stamina） | ダッシュの蓄え（`Stamina`）：ダッシュ中に消費され、少し休むと回復する |
| **ステア**（Steer） | 経路なしで方向を指定して走ること：`NavigationMover.steer()`。ボタンの長押しは、デフォルトでカーソルに向かってステアする |
| **ティック**（Tick） | 物理の1ステップ。毎秒60回 |
| **旋回モード**（Turn mode） | 右ボタンと組み合わせるキーのモードの1つ：キャラクターは進む方向へ向きを変える |
| **ヨー**（Yaw） | 垂直軸周りのカメラの方向 |
| **ズーム**（Zoom） | 0（最も近い）から1（最も遠い）までの値で、カメラの距離と傾きを同時に決める |
