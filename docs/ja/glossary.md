# 用語集

[← ドキュメント目次](index.md)

> これは[英語の原文](../en/glossary.md)の翻訳です。内容が異なる場合は、英語版を参照してください。

このドキュメントとコードで用いる意味を示します。

| 用語 | 意味 |
|---|---|
| **エージェント半径** | ナビゲーションメッシュが障害物から保つ距離。0.5 mで、キャラクターのカプセル半径0.35 mより大きく、経路が角から余裕を保つ |
| **アーム** | `CameraArm`。ターゲットから伸びる線の先にカメラを保持するノード。ホイールで長さを決め、障害物があれば短くなる |
| **ブレンド** | `GroundCharacter.get_locomotion_blend()`。アニメーション用の速度値で、静止は0、走行は1、ダッシュは2 |
| **境界** | 物理レイヤー4の見えないレベル端の壁。キャラクターは衝突し、クリックとカメラアームは通過する |
| **カメラ専用ボディ** | 物理レイヤー3（`camera`）のボディ。アームを止めるが、クリック、ナビゲーション、キャラクターには無視される |
| **キャラクターの状態** | 静止、走行、ダッシュ、ジャンプ、落下のどれをしているか（`GroundCharacter.get_state()`と`state_changed`シグナル） |
| **クリック** | 長押し判定時間内に左ボタンを離すこと。押した地点へ経路をたどる |
| **コヨーテタイム** | 縁から歩いて落ちた後もジャンプできる短い時間（0.1 s） |
| **疲労困憊** | スタミナが尽き、`recover_ratio`（30%）まで回復するまでダッシュできない状態 |
| **向き** | 移動方向とは別にキャラクターが見る方向。横移動や後退時は異なる。`NavigationMover.get_facing()` |
| **落下設定** | ジャンプの頂点以降または縁からの落下を決める重力、最高落下速度、それより速い落下からの減速（`FallSettings`）。ジャンプの上昇には影響しない |
| **浮遊** | ボディが通常どおり歩く間、ヒーローのモデルが地面より上に浮き階段を滑らかに越えること（`CharacterHover`）。浮遊中は歩数がなく、デモでは下降も遅くなる |
| **追従** | 走行するキャラクターの後ろへカメラが自動で回り、傾きと高さを設定値へ近づけること。各動きは滑らかに始まり終わる（`follow_movement`、`follow_pitch`、`follow_zoom`）。オービット後は停止または新しい走行まで待機できる（デモでは`follow_wait_after_rotate`がオン） |
| **歩行周期** | 左右2歩を0から1で表す値（`GroundCharacter.get_gait_cycle()`）。時間ではなく進んだ距離に従う |
| **進行方向** | キャラクターが移動する方向。`NavigationMover.get_heading()` |
| **ヒーローの外見** | 設定で番号を選ぶ、プレイヤーのキャラクター用の10種類のモデルの1つ（`CharacterAppearance`） |
| **長押し** | 左ボタンを長押し判定時間より長く押すこと。キャラクターはカーソルを追う |
| **長押し判定時間** | クリックと長押しを分ける時間。0.2 s（`PointClickMoveInput.hold_delay`） |
| **ジャンプバッファ** | 着地直前のジャンプ入力を記憶し、着地時に発動すること（0.12 s） |
| **照準の維持** | ボタン長押し中にカメラが回るとき、システムカーソルをワールドとともに動かし、同じ地面を指し続けること（`keep_aim_on_camera_turn`） |
| **崖ガード** | `LedgeGuard`。0.5 mより深い落差で止めるか、縁に沿って滑らせる |
| **レベルホスト** | `LevelHost`。現在のレベルを保持し、ローディング画面の背後で切り替えるノード。ヒーローとインターフェースは兄弟ノードで、レベルの一部ではない |
| **ローディング画面** | `LoadingScreen`。レベル切り替え中に直前のフレームをぼかし、場所名、進捗バー、ヒントを表示する |
| **外見** | 「ヒーローの外見」を参照 |
| **見回し** | カーソルを追う長押し中に右ボタンを押し、走行進路を保ったままマウスでカメラだけを回すこと（`look_around_while_held`）。右ボタンを先に押せばカメラの向きへ走る |
| **マーカー** | `ClickMarker`。クリック地点の地面に出るリング |
| **ムーバー** | `NavigationMover`。`move_to`、`steer`、`stop`を毎ティック水平速度へ変える。ボディ自体は動かさない |
| **ナビゲーションメッシュ** | レベルのレイヤー1の衝突形状からベイクする歩行可能領域。島ではレイヤー4の見えない壁も含み、各レベルシーンに保存する。経路はその上で探す |
| **移動の案内** | `TravelPrompt`。確認が必要なポータル上で「○○へテレポート」とキーを表示する。E（`interact`アクション）かクリックで移動し、離れると消える |
| **物理補間** | 物理ティックの間のボディ位置を、表示フレームレートで描画すること。デフォルトはオンで、設定からオフにできる |
| **ピッチ、傾き** | カメラがどれほど急に見下ろすか。コードでは負の角度、設定では正の度数 |
| **静止からの旋回** | `pivot_speed`（1 m/s）未満で即座に向きを変えること |
| **場所** | `PointOfInterest`。プレイヤーが初めて入ると「発見：…」を表示するエリア |
| **操作するヒーロー** | `PlayableHero`（`playable_hero.tscn`）。入力、カメラ、クリックマーカー、経路線を持ち、レベルの隣のゲームシーンに置くヒーロー |
| **ポータル** | `LevelPortal`。別のレベルへつながるエリア。デモのテレポートパッドもポータル |
| **引き寄せ** | キャラクターを隠す障害物の前へカメラを移すこと（`pull_in_on_occlusion`） |
| **急旋回** | `OrbitCameraRig.sharp_turn_speed`（360°/s）より速い、反転などの走行方向の変化。カメラは途中の方向を追わず、その後で新しい方向を追う |
| **ゲーム全体のシーン** | 実行中に残るシーン（`main.gd`付きの`main.tscn`）。レベルホスト、ヒーロー、インターフェース、ローディング画面を含む |
| **横移動** | 右ボタンとキーのモード。横や後ろへ移動してもカメラの向きを見続ける |
| **シルエット** | 遮られたキャラクターを輪郭付きの平坦な形で描くこと（`OccludedSilhouette`） |
| **スポーン地点** | `SpawnPoint`。名前で指定するレベル内の出現地点。各レベルには`default`が必要 |
| **ダッシュ** | Shiftを押すか切り替えをオンにして、スタミナを消費しながら×1.5倍速く走ること |
| **段差の高さ** | ジャンプなしで上れる最大の段差高。0.3 m（`GroundCharacter.max_step_height`） |
| **スタミナ** | ダッシュ用の蓄え（`Stamina`）。ダッシュで消費し、間を置いて回復する |
| **開始レベル** | エディターでレベルホストの下に配置する最初のレベル。`shared/world/world.tscn`の柵付きの草原で、草原とも呼ぶ。ゲーム内では緑の谷（島のパッドの行き先名） |
| **操舵** | 経路なしで指定方向へ走ること。`NavigationMover.steer()`。デフォルトの長押しではカーソルへ操舵する |
| **テレポート** | 走行や急な跳ねを挟まずキャラクターを別の場所へ即座に置くこと。`GroundCharacter.teleport()`、`PlayableHero.teleport()` |
| **ティック** | 物理処理の1ステップ。毎秒60回 |
| **移動者** | ポータルを使えるボディ。ポータルの`traveller_group`（デフォルトは`player`）に属する |
| **旋回モード** | 右ボタンとキーのモード。進む方向へ向きを変える |
| **ウォームアップ** | ローディング画面が消える前に、レベルホストが背後で新しいレベルを描くフレーム。シェーダーのコンパイルとキャラクターの接地を済ませる（`LevelHost.warmup_frames`、3） |
| **ヨー角** | 垂直軸の周りでのカメラの向き |
| **ズーム** | 0（最も近い）から1（最も遠い）の値。距離と傾きを同時に決める |
