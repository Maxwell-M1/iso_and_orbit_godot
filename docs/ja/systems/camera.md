# カメラ

> これは[英語の原文](../../en/systems/camera.md)の翻訳です。内容が異なる場合は、英語版が正しいものとします。

2つのノードで構成されます。`OrbitCameraRig`はターゲットを追い、回転とズームを行います。その子の`CameraArm`はアームの先端で`Camera3D`を保持し、障害物があるとアームを縮めます。

```
CameraRig (OrbitCameraRig)     ターゲットの位置に置かれ、ヨーとピッチで回転する
└── CameraArm (CameraArm)      ローカル+Z方向に伸びるアーム。リグがズームから長さを設定する
    └── Camera3D               アームの先端にあり、アームに沿って逆向きに見る
```

リグはターゲットの子ではなく兄弟です。リグは`_process`でターゲットの補間された位置へ移動し、リグ自身の物理補間はオフです。そうしないと、すでに滑らかにされた位置をさらに滑らかにして、1ティック遅れてしまいます。プロジェクトで物理補間をオンにすると、カメラとキャラクターはどのフレームレートでも滑らかに動きます。

## OrbitCameraRig

- **回転**。右ボタン（`camera_rotate`）を押したままマウスを動かします。回転中はカーソルがキャプチャされ、ボタンを離すと元の位置に戻ります。回転中にウィンドウがフォーカスを失ったりゲームが一時停止したりすると、リグが自分でカーソルを解放します。
- **マウスで傾ける**（`mouse_pitch`、デフォルトでオフ）。右ボタンを押しながらマウスを縦に動かすと、カメラも傾きます。オフでは、傾きはズームだけで決まります。
- **ズーム**。ホイールでカメラを下げて近づけたり、上げて遠ざけたりします。距離と傾きは連動して変わります。
- **追従**（`follow_movement`、`follow_pitch`、どちらもデフォルトでオフ）。カメラは走るターゲットの背後へ徐々に回り込み、傾きを`follow_pitch_angle`へ徐々に合わせます。

### ズームカーブ

ズームは0（最も近い）から1（最も遠い）までの値で、ホイールを1ノッチ回すごとに`zoom_step`（0.1）ずつ変わります。距離は`near_distance`（5 m）から`far_distance`（20 m）まで変わります。傾きは`near_pitch`（−22°）から`far_pitch`（−55°）まで変わりますが、均等ではありません。最上部から`flatten_start_zoom`（0.5、12.5 m、−38.5°）までは均等に変わり、それより下ではカメラがすぐに水平に近づくので、中程度の高さですでにキャラクターの前方が見えます。`flatten_end_zoom`（0.2、8 m）からは、カメラは−22°で見下ろしたまま近づくだけです。

デモは`start_zoom` 0.55で始まります。そこから1ノッチ下げると−33.5°、2ノッチで−26°、3ノッチ（8.75 m）で−22.5°です。

傾きは、ズームによる傾きにオフセットを加えたものです。マウス（`mouse_pitch`がオンのとき）と追従モードはオフセットを変えるので、ホイールとマウスはいつも通り機能し、走行中は傾きが選んだ角度へ徐々に戻ります。`mouse_pitch`をオフにするとオフセットはクリアされます。傾きが`min_pitch`（−80°）と`max_pitch`（−8°）を超えることはありません。

### 追従モード

| プロパティ | デフォルト | 意味 |
|---|---|---|
| `follow_movement` | オフ | 走るターゲットの背後へカメラを回り込ませる |
| `follow_pitch` | オフ | 走行中、旋回と同じ速さ・同じ条件で、傾きを`follow_pitch_angle`へ徐々に合わせる。`follow_movement`なしでも機能する |
| `follow_pitch_angle` | −40° | 目標の傾き（下向きが負）。`min_pitch`と`max_pitch`で制限される |
| `follow_time` | 1.5秒 | ほぼ回りきるまでの時間（角度の5%が残る）。0で即時 |
| `follow_min_speed` | 1 m/s | この速度未満ではカメラは回らない。立っているときやその場旋回では方向が当てにならないため。この速度からその2倍までの間で、回転の強さが滑らかに増す |

デモの設定では別のデフォルト値を使っています：追従時間1.1秒、見下ろし角22°。

次の場合、カメラは追従しません。

- 右ボタンを押している間：両ボタンで走っているときも含め、マウスがカメラを操作します。
- 左ボタンを押してから最初の0.2秒間、クリックか長押しかがはっきりするまで。この一時停止は、`main.tscn`で`CameraRig.set_follow_paused()`に接続された`PointClickMoveInput.hold_pending_changed`から来ます。

ターゲットの速度は、物理ティックごとのターゲットの移動量からリグが測定するので、どんな`Node3D`でもターゲットにできます。

左ボタンを押している間にカメラが回転すると、カーソルは地面の別の地点を指すことになり、キャラクターはそれを追って向きを変え、カメラはキャラクターを追って回転します。こうしてキャラクターはぐるぐる回って走ってしまいます。そのため、ボタンを押している間、入力はシステムカーソルを世界と一緒に動かします。[入力](input.md#ボタン長押し中のカーソル)を参照してください。

## CameraArm

ホイールでアームの長さが決まります。アームは障害物で縮み、余裕ができるとその長さに戻ります。

- **背後のもので止まる**（`keep_out_of_geometry`、デフォルトでオン）。カメラの背後に山、壁、屋根がある場合、カメラは中に入らず、ターゲットの方へ寄ります。山に向かって歩くと、カメラは斜面に入ることなくターゲットに近づきます。離れるように歩くと、背後に余裕ができ次第、元の位置に戻ります。アームが縮むのは、カメラがアームの先端に立てない場合だけです。カメラとターゲットの間に柱や柵があっても、その後ろに余裕があればカメラは動きません。キャラクターはシルエットとして透けて見えます。カメラがそのような障害物のすぐ後ろ、`probe_radius`より近くに立つことになる場合は、そこにカメラの余裕はないので、カメラは障害物の手前へ移動します。
- **ターゲットが隠れたら寄る**（`pull_in_on_occlusion`、デフォルトでオフ）。柵や壁がターゲットをほぼ完全に隠すと、カメラは滑らかに障害物の手前へ移動しますが、ターゲットに`min_pull_in_length`（2.5 m）より近づくことはありません。キャラクターが壁のすぐそばに立っている場合、カメラはキャラクターの背中側へ跳ばずにその場にとどまります。
- **近づくとフェード**。アームがごく短いと、`fade_target`が半透明になります。

| プロパティ | デフォルト | 意味 |
|---|---|---|
| `length` | 10 m | アームの長さ。リグがズームから設定する |
| `camera` | — | カメラ。空なら最初の`Camera3D`の子 |
| `keep_out_of_geometry` | オン | カメラの背後のボディで止まる |
| `probe_radius` | 0.3 m | カメラはこの半径の球として扱われ、壁からこの距離を保つ |
| `collision_mask` | レイヤー1と3 | アームを止めるボディ：`world`と`camera`。キャラクター（レイヤー2）は止めない |
| `ignored_groups` | `camera_ignore` | これらのグループに属するボディ、またはそのグループのノードの下にあるボディはアームを止めない |
| `pull_in_on_occlusion` | オフ | ターゲットが隠れたら寄る |
| `min_pull_in_length` | 2.5 m | ターゲットが隠れたことによって、カメラがこれより近づくことはない。障害物の手前の余裕がこれより少ないと、その場にとどまる |
| `pull_in_sharpness` | 10 | 隠している障害物の手前へカメラが移動する速さ（0で即時）。背後のボディでは常に即座に止まる |
| `occlusion_points` | 胸、頭、膝、両脇 | 見えるかどうかを確認するターゲットの点。アームの始点からの相対位置：右、上、カメラ方向 |
| `occlusion_share` | 0.75 | この割合の点が隠れるとターゲットが隠れたとみなす。細い柱や幹は5点中3点を隠すだけなので、数えない |
| `occlusion_delay` | 0.25秒 | カメラが寄るまでにターゲットが隠れ続けている必要がある時間、および戻るまでに見え続けている必要がある時間 |
| `return_delay`、`return_sharpness` | 0.3秒、4 | アームはすぐに縮むが、伸びて戻るのは少し間を置いてから滑らかに行うので、柱の間でカメラがぴくぴく動かない。戻る途中にあるボディは通り抜けず、飛び越える |
| `fade_target` | — | 近づいたときに半透明になる対象（デモでは`Player/Visual`） |
| `fade_start_length`、`fade_end_length`、`fade_transparency` | 1.5 m、0.7 m、0.75 | 1つ目の長さでターゲットがフェードし始め、2つ目の長さで75%透明になる |
| `debug_draw` | オフ | アーム（灰色：ホイールによる長さ、緑：現在の長さ）、カメラの球、ターゲットの点へのレイ（赤：隠れている）を描画する。別のカメラから見える |

メソッド：`snap()`、`get_current_length()`、`is_pulled_in_by_occlusion()`。

### カメラ専用のボディ

物理レイヤー3（`camera`）に置きます。キャラクターはこれと衝突せず、クリックやナビゲーションからも見えません。家の屋根（`shared/world/props/house.tscn`の`RoofCameraBlocker`）にはこのようなボディがあります。カメラは屋根で止まりますが、誰も屋根に登ったり、屋根を横切る経路を引いたりできません。

### `camera_ignore`グループ

このグループは、グループに属するノードの下にあるものすべてにも適用されます。プロップシーンのルートに一度設定すれば、レベル内のすべてのインスタンスに適用されます。レベルのフォルダー用ノードに設定してもかまいません。デモでは必要ありません。木の幹（最大2.4 m）は、最も近いズーム（地面から3 m）でもカメラより低いからです。

### アームが障害物の後ろの空間とボディの内部をどう区別するか

まずアームは、カメラがアームの先端に立てるかどうかを確認します。つまり、そこで球がカメラの手前の障害物も含めて何にも触れておらず、先端がボディの内部にないことです。カメラからターゲットへのレイは、開始点で自身が内部にいるボディの面を検出しないので、カメラの手前にある障害物の奥側の面を見つけます。その面からアームの先端へのレイは、カメラが入り込んでいるボディに入り、そこから出ることはありません。何かが邪魔をしていれば、その面からカメラに向かって球をキャストし、ほかのボディは通り過ぎて、邪魔をしているボディの手前で止めます。アームがかすめるだけの柱ではカメラは動きません。

Joltは、キャストの開始時点で球が触れているボディも、キャストがその内部から始まるメッシュのボディ（山など）も報告しません。そのため、その面のすぐ後ろに別のボディがある場合（後ろに崖がある柵）や、キャストが別のボディの内部から始まることになる場合（近接した2枚の薄い岩の張り出しに、アームがほぼ沿っている場合）は、ターゲットに近い側で空いている空間を探します。

戻る道筋も確認します。アームが伸びて戻るのを待っている間に向きが変わると、保っている長さのままではカメラが壁の中に入ってしまうことがあります。その場合、カメラはすぐに空いている長さへ移ります。カメラと戻り先の間にボディがある場合（カメラが柵の手前にいて、今は柵の後ろに余裕がある場合）は、間を置いた後、カメラはボディの中を通り抜けずに飛び越えます。

## 測定された挙動

`tests/camera_checks.gd`と`tests/camera_arm_checks.gd`より：

- カメラに対して90°の方向へ走るときの追従：`follow_time`が0なら0.17秒で95%回り、デモの1.1では1.23秒です。10では2秒後に90°のうち39°しか回っていません。立っているときは回りません。右ボタンを押している間は回らず、離すと回転を続けます。
- 追従オン（1.1秒）で左ボタンを長押し：最初の0.2秒間カメラは動かず（短いクリックでは動かない）、その後1.25秒で走りの背後へ向けて28.3°のうち27.1°回り、その間に走る方向は0.01°しか変わりません。「即時」でも同様です。マウスを150 px動かすと走る方向が25°変わり、新しい方向が保たれます。`keep_aim_on_camera_turn`がオフだと、キャラクターは1.25秒で77.6°曲がっていきます。
- 傾きの揃え：ホイールで下げたカメラ（下向き22.5°）は、`follow_time` 0.5で55°へ徐々に変わり、約0.65秒で95%に達します。旋回がオフなら走りの後ろへは回りません。89°はカメラの制限である80°に抑えられます。追従と20°の傾きで左ボタンを長押し：傾きは20°へ向かう途中、1.25秒で80°から22.5°になり、走る方向は0.01°変わります。
- アーム：開けた場所では最大の長さ。背後の崖では即座に止まります。崖に向かって歩くと、カメラは近づいて崖の外にとどまります。崖がなくなると、アームは少し間を置いて滑らかに戻ります。すぐ後ろに崖がある柵：カメラは柵の手前で止まります。カメラのすぐ背後の柵：カメラは柵の手前へ移動します。カメラが戻るのを待っている場所に現れた柵：カメラはすぐに柵の後ろへ移ります。カメラとキャラクターの中間にある柵：デフォルトではカメラは柵の後ろにとどまり、接近ありでは滑らかに柵の手前へ移動します。短い遮蔽は数えません。キャラクターのすぐそばの柵：カメラはキャラクターの背中側へ跳びません。細い柱は数えず、アームをかすめる柱はカメラを動かさず、`camera_ignore`に属するボディはカメラを止めず、近づくとキャラクターは半透明になります。レベル上では、迷路の生け垣、山の斜面と薄い岩の張り出し、テント、山頂の石のそばで、カメラはそれらの中に入りません。
