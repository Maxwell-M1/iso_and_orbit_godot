# キャラクター

> これは[英語の原文](../../en/systems/characters.md)の翻訳です。内容が異なる場合は、英語版が正しいものとします。

キャラクターのモデルはスクリプトでプリミティブ（カプセル、円柱、球、角柱）から組み立てられ、ロジックとは別に`shared/characters/`に置かれています。同じモデルを主人公にも、レベルに立たせるキャラクターにも使えます。

## モデルと装備

| モデル（`shared/characters/models/`） | 人物 | 装備 |
|---|---|---|
| `knight.tscn` | 騎士：板金鎧、T字型の覗き穴と赤い羽飾りの付いたバケツ型の兜、十字の入った赤いサーコート、肩当て | 剣、十字の入った丸盾 |
| `ranger.tscn` | レンジャー：尾の付いた緑のフード、その陰に淡い色の目、背中に矢筒 | 弓 |
| `mage.tscn` | 魔法使い：金の縁取りのある釣鐘型の紫のローブ、先の曲がったとんがり帽子、白いひげ | 輪をまとって浮かぶ光る球、呪文書 |
| `dwarf.tscn` | ドワーフ：背が低く幅広、ビーズを付けた赤いひげ、鼻、角付きの兜 | 両手斧 |
| `rogue.tscn` | 盗賊：暗い色のフード、黄色い目、赤いマスク、3枚のパネルからなるマント、ベルトポーチ | 2本の短剣（左は逆手持ち） |

すべてのモデルが従う決まり：

- −Zを向き、足が原点にあります。
- 手は空のノード`RightHand`と`LeftHand`（「見えない手」）です。`equipment/`のシーン（杖、剣、盾、弓、斧、短剣、本、球）を手に入れます。装備の原点は握る位置です。武器を変えるには、手のノードの子を置き換えます。ゲーム内で実行時に行うことも、モデルのシーンで恒久的に行うこともできます。アイテムの傾きは、手の中でのその回転です。
- 装備で共有するマテリアル（鋼、真鍮、革、骨、光る宝石と目）は`materials/`にあります。体と服の色はモデルのシーン内にあります。

モデルは`shared/characters/models/mage_options/`に、その杖は`equipment/staff*.tscn`にあります。手は体の軸から0.52 mの位置にあるので、杖の下端がローブにめり込みません。大魔導士は0.55 m、戦闘魔導士は0.49 mの位置で杖を持ちます。主人公の外見には`RightHand`しかありません。戦闘魔導士の本は`LeftHip`に下がっています。

レベル内では、10体すべてが南の壁の南側に、壁を背にして（壁の隙間の東側）一列に並び、南を向いて、頭上にそれぞれの番号を表示しています。列全体の前には何もない通路があります。

## CharacterAppearance

実行時にモデルを切り替えます（設定 → キャラクター → **主人公の外見**）。`set_look(number)`は古いモデルを削除し、同じ名前で新しいモデルをその場所に置きます。また、新しいモデルの物理補間をリセットし（そうしないとモデルが原点から滑り込んでくる）、新しいモデルの`RightHand`を`HandSway`に渡すので、杖が再び歩みに合わせて揺れます。シルエットは新しいメッシュを自動で取り込みます。

| プロパティ | デフォルト | 意味 |
|---|---|---|
| `slot` | — | モデルを保持するノード（プレイヤーでは`Visual`。`GroundCharacter`が回転させる） |
| `model_name` | `Model` | `slot`内のモデルノードの名前 |
| `models` | — | 選択肢となるモデルのシーン。外見の番号はこのリスト内の位置（1から） |
| `hand_sway` | — | 新しいモデルの手を受け取るノード。空なら手は揺れない |
| `hand_path` | `RightHand` | モデル内でアイテムを持つ手の位置 |

`get_look()`は現在の番号（リストにないモデルなら0）を、`get_model()`はモデルのノードを返します。シグナル：`look_changed(model)`。

## HandSway：脇に貼り付かず、手に握られた杖

`HandSway`（プレイヤーでは`RightHandSway`）は、モデルの手のノードを静止位置からの相対で動かします。

- **歩みに合わせて**。足音と同じリズムである`GroundCharacter.get_step_phase()`に従います。ステップのたびに手は端（前と後ろが交互、±7 cm）にあって最も低く（2.5 cm）なり、ステップの中間では中央にあります。アイテムは傾きが少し遅れます（±7°）。揺れは速度とともに大きくなり、ダッシュ中は1.5倍になり、キャラクターが止まるか空中にいると消えていきます。
- **走行中**はアイテムが前に傾きます（6°）。
- ばねによる**慣性**（1.8 Hz、減衰0.45）：加速時には先端が後ろへ、減速時には前へ、旋回時には外側へ傾き、落ち着くまで揺れます。着地時には、落下が速いほど手が深く沈み、踏み切り時には少しだけ沈みます。

物理ティックでボディの後に実行されるので、物理補間がボディと同じように滑らかにします。ステップのリズムは連続しています。ステップの途中で止まると、次のステップは再び動き出してから`first_step_distance`の位置で来ますが、フェーズは跳ばず、そのステップで整数に達します。別の手やNPCには、それぞれの手を持つ別の`HandSway`を追加してください。振幅、傾き、ばねは、Swing（揺れ）とInertia（慣性）のグループにあるエクスポートされたプロパティです。

## OccludedSilhouette：1つの形、輪郭付きの武器、縁取り

何か（山、家、木）が主人公を隠しているところでは、主人公は水色のシルエットとして表示されます。体は1つの平坦な形、手に持った装備はその上に輪郭付きで描かれ、全体の周りに縁取りが付きます。

`OccludedSilhouette`（プレイヤーでは`Silhouette`）は、後から追加されたメッシュ（新しい外見や武器。`SceneTree.node_added`経由）も含め、モデルのすべてのメッシュに`material_overlay`を設定します。モデル自身のマテリアルは変わらないので、レベル内の同じモデルにはシルエットが出ません。体のメッシュと手のノードの下のメッシュ（`gear_nodes`：`RightHand`、`LeftHand`）には、異なるパスのチェーンが設定されます。

各画面ピクセルは、ステンシルバッファによって1回だけ塗られます。パスはステンシル値が自分の値より小さいところにだけ描画し、すぐに自分の値を書き込みます（`stencil_mode read, write, compare_greater, N`）。シェーダーとマテリアルは`addons/iso_orbit/occluded_silhouette/`にあります。

| パス | `render_priority` | ステンシル | 処理 |
|---|---|---|---|
| `silhouette_mask` | 1 | 4を書き込む | 不可視、深度テストあり：キャラクター自身が見えている場所に印を付け、そこにはほかに何も描かれないようにする |
| `silhouette_body` | 2 | < 2 → 2 | 体の平坦な塗りつぶし：パーツは重ならず、1つの形にまとまる |
| `silhouette_gear` | 3 | < 3 → 3 | 装備用の明るめの塗りつぶし。体の上に独自の輪郭付きで描く |
| `silhouette_outline` | 4 | < 1 → 1 | 縁取り：メッシュを法線方向に画面の高さの0.4%だけ膨らませる。形全体の外側にある部分だけが残る |

塗りつぶしと縁取りは、障害物がフラグメントより少なくとも30 cm手前にある場所にだけ描かれます（深度バッファは`silhouette_common.gdshaderinc`でメートルに変換されます）。透明なオブジェクトはまず`render_priority`で並べ替えられるので、パスはすべてのメッシュについて一度に順番どおり実行されます。

`outline_enabled`（設定 → 表示 → **障害物の裏のシルエット輪郭**）は、チェーンから最後のパスを取り除きます。縁取りの幅は`silhouette_outline.tres`の`width`パラメーターで、色は塗りつぶしと縁取りそれぞれの`color`です。

エンジンに関する注意点が2つあります。ステンシルバッファはGodot 4.5以降で実験的機能であり、透明パスでしか読めません。また、Godot 4.7（D3D12とVulkan）では、シェーダー内の投影がY方向に反転しています。`PROJECTION_MATRIX[1][1]`が負になります。`abs()`がないと「画面に対する割合 → メートル」の変換が負になり、縁取りのメッシュが縮んで縁取りが消えます。

## モデルの編集

モデルはスクリプトでプリミティブから組み立てられたもので、今は普通のシーンです。ほかのシーンと同じようにエディターで編集してください。
