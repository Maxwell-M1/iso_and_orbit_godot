# はじめに

> これは[英語の原文](../en/getting-started.md)の翻訳です。内容が異なる場合は、英語版が正しいものとします。

## 動作要件

- Godot 4.7.2（標準版または.NET版）。プロジェクトにはまだC#コードがないので、どちらでも動作します。
- デモにはほかに何も必要ありません。Jolt Physicsはエンジンに組み込まれており、レンダラーはForward+で、すべてのアセットはリポジトリに含まれています。

## 開いて実行する

1. リポジトリをクローンします。
2. プロジェクトマネージャー（Project Manager）で**インポート**（Import）を選んで`project.godot`を指定し、プロジェクトを開きます。`.godot/`キャッシュはリポジトリに含まれていないため、最初のインポートには少し時間がかかります。
3. F5を押します。メインシーンは`res://gdscript/main.tscn`です。

## 画面に表示されるもの

主人公は、柵に囲まれた草地の中央にあるスポーン地点に立っています。操作方法は左上に、フレームレートは右上に表示されます。

- 地面を**左クリック**：主人公は障害物を避けてそこへ走り、マーカーがその地点を示します。
- **左ボタンを長押し**：主人公はカーソルを追って走ります。
- **右ボタン + マウス**：カメラを回します。**ホイール**：ズーム。
- **両ボタン**：カメラの向きへ走ります。**右ボタン + WASD**：カメラ基準で移動します。
- **Shift**でダッシュ、**スペース**でジャンプ、**F10**で設定を開きます。

全リストは[操作方法](controls.md)にあります。

歩いて行ける場所：

- **古代の円環**：スポーン地点の北西にある列柱の輪。柱の間を歩くと、柱の裏の主人公がシルエットで表示されます。
- 東の**旅人の野営地**と南西の**井戸のそばの農家**。NPCがいます。
- 北東の山、**吹きさらしの峰**：頂上をクリックすると、主人公はらせん状の山道をたどります。
- 経路探索のテスト用の、生け垣の迷路、スロープ付きのプラットフォーム、スポーン地点近くのU字型の罠。
- 南の壁沿いに一列に並んだ10種類の主人公の外見。設定 → キャラクター → **主人公の外見**で1つを選べます。

## 設定

F10で設定ウィンドウが開き、ゲームが一時停止します。EscまたはF10で閉じます。設定は`user://settings.cfg`に保存され、すぐに反映されます。操作ヒントを隠すには、設定 → インターフェース → **操作ヒントと速度**をオフにします。インターフェースの言語も同じタブで選べます。すべての設定：[設定](settings.md)。

## テストを実行する

```bash
godot --headless --fixed-fps 60 --path . --script res://tests/run_checks.gd
```

ここで`godot`はGodot 4.7.2の実行ファイルです。Windowsでは、出力を表示して終了コードを得るために`_console.exe`版を使ってください。クローンしたばかりの場合は、先にエディターで、または`godot --headless --path . --import`で、プロジェクトを一度インポートしてください。詳細：[テスト](testing.md)。
