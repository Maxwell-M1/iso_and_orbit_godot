# 操作方法

[← ドキュメント目次](index.md)

> これは[英語の原文](../en/controls.md)の翻訳です。内容が異なる場合は、英語版が正しいものとします。

マウスとキーボードで操作します。ゲームパッドには対応していません。以下の挙動のほとんどは設定ウィンドウ（F10）で変更できます。[設定](settings.md)を参照してください。入力の内部の仕組み：[入力](systems/input.md)。

このページやほかのドキュメントに記載したキーとボタンは、Project Settings → Input Mapで設定したデモのデフォルトです。ゲーム内、設定ウィンドウ、ローディング画面のヒントには、現在割り当てられたキー名が表示され、変更後は新しい名前へ変わります（[文章内のキー名](systems/ui.md#文章内のキー名)を参照）。

| 入力 | 動作 |
|---|---|
| 地面を左クリック | 障害物を避けてその地点へ走る。地面にマーカーが表示される |
| 左ボタンを長押し | カーソルを追って走る。走っている間はカーソルが隠れる |
| 左ボタンを長押ししてから右ボタン | 走りながら見回す。マウスはカメラを回し、ヒーローは進路を保つ。右ボタンを離せばマウスで再び操舵できる |
| 右ボタンを押してから左ボタン、またはほぼ同時 | カメラの向きへ走る。マウスでカメラを回すとヒーローも曲がり、A／Dで斜め前へ進む。左ボタンを離すか、どの順番でも両方を離せば止まる |
| 右ボタン + マウス | 主人公の周りでカメラを回す。終わるとカーソルは元の位置に戻る |
| 右ボタン + WASD | カメラ基準で、横移動または旋回しながら移動する（下記参照）。キーかボタンを離すと止まる |
| マウスホイール | カメラを下げて主人公に近づける、または上げて遠ざける |
| Shift | 押している間ダッシュ、または押すたびに切り替え（設定で選択）。疲労がオンなら、スタミナが続く間だけ。スタミナバーは画面下部にある |
| スペース | ジャンプ |
| E | テレポートパッド上で移動先へ行く。画面の案内をクリックしてもよい |
| F10 | 設定（ゲームを一時停止）。EscまたはF10で閉じる |

## クリックと長押し

押下がクリックか長押しかは、0.2秒後に判定されます。

- **クリック**（それより早く離した場合）：その後マウスが動いても、主人公は押した地点まで経路に沿って走り、そこにマーカーが表示されます。走り出すのはボタンを離したときです。主人公が到着するか、長押しやキーで操作を引き継ぐと、マーカーは消えていきます。
- **長押し**（それより長く押した場合）：主人公はすぐにカーソルを追って走り、押した地点の方を向くことはありません。

判定が出るまで、主人公はそれまでの動作を続けます。

長押し中に主人公がどう追従するか（設定 → 操作 → **左ボタン長押し**）：

- **カーソルへ直進**（デフォルト）：経路探索をしません。主人公は障害物に沿って滑り、スロープのどこを指しても駆け上がり、ボタンを離すと滑らかに止まります。
- **経路に沿って地点へ**：主人公はカーソル下の地点までのナビゲーション経路をたどります。高低差の近く（スロープ、プラットフォーム）では、経路がルート間で切り替わることがあります。ボタンを離すと、主人公は最後の地点まで走り続けます。

左ボタン長押し中にカメラが自動で回る場合（追従モード）、カーソルもワールドと一緒に動いて狙った地点を指し続けるため、ヒーローは進路を保ちます。走りながら右ボタンで見回すときも同じです。設定 → カメラ → **カメラ回転中もカーソルが狙いを保つ**。

## 両ボタンを押す順序と結果

右ボタンは常にカメラを回します。走行も操舵するかは押す順序で決まります。次はデフォルト設定での動作です。

| 操作 | ヒーロー | カメラ |
|---|---|---|
| 左ボタンを長押し | カーソルへまっすぐ走る | 動かない（追従はデフォルトでオフ） |
| …次に右ボタンも押してマウスを動かす | 同じ進路を保つ。見回しでは操舵せず、キーも効かない | ヒーローの周りを回る |
| …右ボタンを離し、左は押したまま | 同じ進路を保つ。隠れたカーソルが狙った地点にあり、そこからマウスで再び操舵する | 選んだ向きに留まる |
| …または左ボタンを先に離す | 滑らかに止まる。右ボタンを離すと狙った地点へカーソルが現れる | 右ボタンを離すまで回る |
| 右ボタンの後に左ボタン、または0.2 s以内に両方 | カメラの向きへ走り、カメラと一緒に曲がる。A／Dで斜め前へ進む | マウスに従って回る |
| …右ボタンを離し、左は押したまま | マウスが動くまでカメラの進路を保つ。その後、ヒーローの4 m前方へ置いたカーソルが操舵する | 選んだ向きに留まる |
| …マウスを動かす前に右ボタンを再び押す | 再びカメラの向きへ走る。マウスが動いてカーソル操舵になった後なら、右ボタンは見回しになる | マウスに従って回る |
| 左ボタンを離す | 約4分の1秒で滑らかに止まる。右ボタンとWを押していれば代わりにキーで歩き続ける | — |
| マウスを動かさず、任意の順序と間隔で両ボタンを離す | カーソルへ曲がらず、現在の進路上で止まる | — |
| クリックしてから右ボタン | クリックした地点まで走り続ける | ヒーローの周りを回る |
| 右ボタン＋WASD | カメラを基準に歩き、進む方向を向く | マウスに従って回る |

停止せずに見回しからカメラ方向への走行へ切り替えるには、右ボタンを押したまま左ボタンを押し直します。

### 設定で変わる動作

- **左ボタンで走行中の右ボタンはカメラを回すだけ**（操作）をオフにすると、右ボタンは押す順序に関係なく走行を操舵します。カーソルを追う走行中に押すと、ヒーローはカメラの向きへ即座に曲がります。
- **カメラ回転中もカーソルが狙いを保つ**（カメラ）をオフにすると、見回し中もカーソルが画面上に留まり、走行がカメラとともに弧を描いて曲がります。走行を追うカメラも同様に進路を変えます。
- **左ボタン長押し → 経路に沿って地点へ**（操作）では、カーソル下の地点へ経路をたどります。見回し中とその後マウスが動くまでは、走行先はカーソル下ではなくヒーローに対する相対位置を保ちます。別の角度から見たカーソルがスロープや足場を指すかもしれないためです。左ボタンを離すと最後の地点まで走ります。
- **左ボタン長押しで走る間はカーソルを隠す**（操作）をオフにすると、見回し後のカーソルが以前の位置から、カメラの回転に合わせて画面上を移動した照準位置へ跳びます。
- **走る方向へカメラを回す**、**走る間カメラの傾きを揃える**、**走る間カメラの高さを揃える**（カメラ）を有効にすると、カーソル長押しやクリック地点への走行中に視点が滑らかに後ろへ回ります。右ボタンを押している間は追従しません。見回し中を含め手動で回した後は、ヒーローが止まるか、新しい地点へのクリックまたは新しい長押しで走行を始めるまで視点を保ちます。減速中や以前のクリック地点へ向かう間に急に回りません。キー移動には右ボタンが必要なため、その間は追従しません。
- **右ボタン＋WASD**と**左＋右ボタン＋A/D**（操作）ではキーの移動方式を選びます。以下を参照してください。

## 右ボタンと組み合わせるキー

WASDは右ボタンを押している間だけ機能します。押していなければ何も起きません。モードは右ボタンのみ（**右ボタン + WASD**）と両ボタン（**左右ボタン + A/D**）で別々に選べ、それぞれに**オフ**と2つのバリエーションがあります。

| | 横移動 | 旋回 / 斜め（デフォルト） |
|---|---|---|
| 右ボタン + W | 前方、カメラの向きへ | 同じ |
| 右ボタン + A / D | 前を向いたまま横へ | 左 / 右へ向きを変えてその方向へ進む |
| 右ボタン + S | 前を向いたまま後ろへ、遅め | 振り返ってカメラの方へ歩く |
| 2つのキー（W + A、S + D…） | 前を向いたまま斜めに | 進む方向を向いて斜めに |
| 左右ボタン + A / D | 前を向いたまま斜め前へ | 進む方向を向いて斜め前へ |

斜め移動は直進と同じ速さです。後退はデフォルトで30%遅くなります（5.5ではなく3.85 m/s。設定 → 操作 → **後退（S）の減速**）。斜め後ろへの移動は一部だけ減速し（横移動でS + D：21%）、真横へはまったく減速しません。そのため、減速は横移動モードにしか存在しません。

停止後も主人公はそれまでの向きを保ちます。クリックや長押しをすると、再び走る方向を向きます。

モードを**オフ**にすると、操作ヒントから対応する行も消えます。両ボタンとキーの組み合わせは[両ボタンを押す順序と結果](#両ボタンを押す順序と結果)を参照してください。

移動キーは米国QWERTYキーボードのWASDの物理的な位置に割り当てられています。表示される文字は配列に従い、AZERTYなら同じ位置がZQSDです。Project Settings → Input Mapで変更できますが、デモにはゲーム内のキー割り当て画面はまだありません。

## カメラ

- **回転**：右ボタンとマウス。設定 → カメラ → **右ボタンでカメラを上下に傾ける**がオンなら（デフォルトはオフ）、縦の動きでカメラも傾きます。
- **ズーム**：ホイールで距離と傾きが同時に変わります。中間より下ではカメラがすぐに水平に近づくので、前方が見えます。
- **追従**（デフォルトはオフ）：設定 → カメラ → **走る方向へカメラを回す**、**走る間カメラの傾きを揃える**、**走る間カメラの高さを揃える**。右ボタンを押している間と左ボタン押下の最初の0.2 sは追従しません。見回し中を含め、右ボタンで回した後は、ヒーローが止まるか左ボタンで新たな走行（クリックまたは長押し）を始めるまでその視点を保ちます。減速中やクリック済み地点への走行中に視点が回り出すことはありません。キー移動には右ボタンが必要なため追従しません。
- **障害物**：カメラは背後の山、壁、屋根で止まります。オプションで、障害物が主人公を隠すとカメラが寄ります。障害物の裏では、主人公はシルエットで表示されます。

詳細：[カメラ](systems/camera.md)。

## テレポート

古代の円環のそばの光るパッドから孤島へ行き、島のパッドから戻れます。上に乗ると画面下部に「E ○○へテレポート」と案内が現れ、離れると消えます。Eを押すか案内をクリックします。ダッシュしてパッドに乗った後、Shiftを押したままでもEが使えます。ローディング画面が切り替えを覆い、ヒーローは向こうのパッドの隣へカメラを背後にして到着し、操作が戻ります。切り替え中ずっと左ボタンを押していた場合、次に押し直すまで入力と数えません。押し続けているキー（右ボタン＋W/A/S/D、またはShift）は直ちに再び効きます。詳細は[レベル](systems/levels.md)を参照してください。

## ダッシュとジャンプ

- **ダッシュ**：Shiftを押していて主人公が移動している間、1.5倍速くなります。疲労がオンなら、スタミナは5秒持ちます。尽きると、30%まで回復するまで主人公は通常の速さで走り、Shiftを押したままなら自動的に再びダッシュします。Shiftを押したまま立ち止まっていてもスタミナは減りません。切り替えモードでは、1回押すとダッシュがオンになり、次に押すとオフになります。主人公が疲れ切ったときにもオフになります。
- **ジャンプ**：高さ1 m。着地の少し前に押したジャンプは着地時に発動し、縁から歩いて落ちた直後に押したジャンプも有効です。落下防止は縁からのジャンプを妨げません。

詳細：[ロコモーション](systems/locomotion.md)。
