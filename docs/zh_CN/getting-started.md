# 快速上手

[← 文档目录](index.md)

> 本文是[英文原文](../en/getting-started.md)的翻译。两者不一致时，以英文版为准。

## 环境要求

- Godot 4.7.2。标准版即可：项目使用 GDScript，不需要 .NET SDK。
- 运行演示无需其他任何东西：Jolt Physics 已内置于引擎，渲染器为 Forward+，所有资源都在仓库中。

## 打开并运行

1. 克隆仓库。
2. 在项目管理器（Project Manager）中选择**导入**（Import），选中 `project.godot`，然后打开项目。由于 `.godot/` 缓存不在仓库中，首次导入需要稍等片刻。
3. 按 F5。主场景是 `res://gdscript/main.tscn`。

演示会加载你之前保存的设置。要得到本文所述默认状态，请按 **F10 → 全部重置**。全新克隆的项目请先等待导入完成，再打开脚本或运行测试。不要从其他项目复制 `.godot/` 缓存。

## 你会看到什么

英雄站在一片围着栅栏的林间空地中央的出生点。操作说明显示在左上角，帧率显示在右上角。

- **左键点击**地面：英雄绕开障碍物跑过去，并有标记显示该点。
- **按住左键**：英雄跟随光标奔跑。
- **右键 + 鼠标**：环绕旋转相机。**滚轮**：缩放。
- **先按右键，再按左键**：向相机所看方向奔跑。**按住左键，再按右键**：奔跑时环顾四周。**右键 + WASD**：相对相机移动。
- **Shift** 冲刺，**空格**跳跃，**F10** 打开设置。

完整列表见[操作](controls.md)。

可以前往的地点：

- **远古石环**：出生点西北方的一圈石柱。在石柱之间行走时，英雄在石柱后会显示为剪影。
- 东边的**旅人营地**和西南边的**井边农庄**，那里有 NPC。
- **风啸峰**：东北方的山。点击山顶，英雄会沿螺旋山路上山。
- 出生点附近的树篱迷宫、带坡道和台阶的平台，以及 U 形陷阱，用于测试寻路。
- 南墙边排成一排的十种英雄外观。在设置 → 角色 → **英雄外观**中选择。
- **远古石环**旁的传送台上有旋转的水晶：站上去按 E 或点击提示，即可前往**孤岛**及其**隐士营地**。岛上的传送台（“传送至翠谷”）会把你送回来。

## 设置

F10 打开设置窗口并暂停游戏；按 Esc 或 F10 关闭。设置保存到 `user://settings.cfg`，并立即生效。要隐藏操作提示，关闭设置 → 界面 → **操作提示和速度**。界面语言也在同一选项卡中选择。所有设置：[设置](settings.md)。

## 运行测试

```bash
godot --headless --fixed-fps 60 --path . --script res://tests/run_checks.gd
```

这里的 `godot` 指你的 Godot 4.7.2 可执行文件。在 Windows 上请使用 `_console.exe` 版本，才能看到输出并获得退出码。刚克隆的仓库需要先导入一次项目，可以在编辑器中导入，也可以运行 `godot --headless --path . --import`。详见：[测试](testing.md)。
