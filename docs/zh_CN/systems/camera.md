# 相机

> 本文是[英文原文](../../en/systems/camera.md)的翻译。两者不一致时，以英文版为准。

两个节点：`OrbitCameraRig` 跟随目标、环绕和缩放；其子节点 `CameraArm` 在相机臂末端持有 `Camera3D`，并在遇到障碍物时缩短相机臂。

```
CameraRig (OrbitCameraRig)     放在目标处，按偏航角和俯仰角旋转
└── CameraArm (CameraArm)      沿局部 +Z 方向的相机臂；相机支架根据缩放设置其长度
    └── Camera3D               位于相机臂末端，沿相机臂往回看
```

相机支架是目标的兄弟节点，而不是子节点。它在 `_process` 中移动到目标的插值位置，自身的物理插值是关闭的：否则它会对已经平滑过的位置再做一次平滑，并滞后一个物理帧。在项目中开启物理插值后，相机和角色在任何帧率下都能平滑移动。

## OrbitCameraRig

- **环绕。** 按住右键（`camera_rotate`）并移动鼠标。环绕期间光标被捕获，松开按键后回到原来的位置。如果在环绕过程中窗口失去焦点或游戏暂停，相机支架会自行释放光标。
- **用鼠标倾斜**（`mouse_pitch`，默认关闭）。按住右键时，鼠标的垂直移动也会倾斜相机。关闭时，倾角只由缩放决定。
- **缩放。** 滚轮让相机向下拉近或向上拉远。距离和倾角同时变化。
- **跟随**（`follow_movement`、`follow_pitch`，默认均关闭）。相机逐渐转到奔跑中的目标身后，并将倾角平滑调整到 `follow_pitch_angle`。

### 缩放曲线

缩放是一个从 0（最近）到 1（最远）的值；滚轮每滚动一格改变 `zoom_step`（0.1）。距离从 `near_distance`（5 米）到 `far_distance`（20 米）。倾角从 `near_pitch`（−22°）到 `far_pitch`（−55°），但变化并不均匀：从最高处到 `flatten_start_zoom`（0.5，12.5 米，−38.5°）均匀变化，低于该点后相机迅速趋于水平，因此在中等高度就能看清角色前方。从 `flatten_end_zoom`（0.2，8 米）开始，相机保持 −22° 的倾角，只是继续拉近。

演示从 `start_zoom` 0.55 开始。从这里往下滚一格：−33.5°，两格：−26°，三格（8.75 米）：−22.5°。

倾角等于缩放倾角加上一个偏移量。鼠标（开启 `mouse_pitch` 时）和跟随模式改变的是偏移量，因此滚轮和鼠标照常工作，奔跑中倾角又会平滑回到所选角度。关闭 `mouse_pitch` 会清除偏移量。倾角永远不会超出 `min_pitch`（−80°）和 `max_pitch`（−8°）。

### 跟随模式

| 属性 | 默认值 | 含义 |
|---|---|---|
| `follow_movement` | 关 | 将相机转到奔跑中的目标身后 |
| `follow_pitch` | 关 | 奔跑中将倾角平滑调整到 `follow_pitch_angle`，速率和适用情况与转向相同；不开启 `follow_movement` 也能工作 |
| `follow_pitch_angle` | −40° | 目标倾角（向下为负），受 `min_pitch` 和 `max_pitch` 限制 |
| `follow_time` | 1.5 秒 | 几乎转到位所需的时间（剩余 5% 的角度）；0 表示立即 |
| `follow_min_speed` | 1 米/秒 | 低于此速度时相机不转动：站立或原地转身时，方向不可靠。在此速度与其两倍之间，转动力度平滑增强 |

演示的设置使用不同的默认值：跟上用时 1.1 秒，向下倾角 22°。

以下情况相机不会跟随：

- 按住右键时：由鼠标控制相机，包括同时按住两键奔跑时；
- 按下左键后的前 0.2 秒内，直到确定是点击还是按住为止。这一暂停来自 `PointClickMoveInput.hold_pending_changed`，它在 `main.tscn` 中连接到 `CameraRig.set_follow_paused()`。

目标的速度由相机支架根据目标每个物理帧的移动来测量，因此任何 `Node3D` 都可以作为目标。

如果按住左键时相机转动，光标就会指向地面上的另一处，角色随之转向，相机又随角色转动：角色会原地兜圈。因此在按住按键期间，输入组件会让系统光标随世界一起移动。见[输入](input.md#按住按键时的光标)。

## CameraArm

滚轮设置相机臂长度；相机臂遇到障碍物时缩短，有空间时恢复到该长度。

- **遇到后方物体时停下**（`keep_out_of_geometry`，默认开启）。相机后方有山、墙或屋顶时：相机不会进入其中，而是向目标靠近。朝山走去时，相机会向目标靠近，而不会进入山坡；往回走时，一旦后方有了空间，相机就会退回原位。只有当相机无法停在相机臂末端时，相机臂才会缩短。相机和目标之间的柱子或栅栏，如果其后方有空间，不会移动相机：角色会以剪影形式透过它显示。如果相机会紧贴在这类障碍物的背面，距离小于 `probe_radius`，那里就没有相机的空间，相机会移到障碍物前方。
- **目标被遮挡时拉近**（`pull_in_on_occlusion`，默认关闭）。栅栏或墙几乎完全遮住目标时：相机平滑移到障碍物前方，但离目标绝不近于 `min_pull_in_length`（2.5 米）。如果角色紧贴墙站立，相机会保持不动，而不是跳到角色背后。
- **近距离淡化。** 相机臂很短时，`fade_target` 变为半透明。

| 属性 | 默认值 | 含义 |
|---|---|---|
| `length` | 10 米 | 相机臂长度；由相机支架根据缩放设置 |
| `camera` | — | 相机；为空时使用第一个 `Camera3D` 子节点 |
| `keep_out_of_geometry` | 开 | 遇到相机后方的物体时停下 |
| `probe_radius` | 0.3 米 | 相机被视为该半径的球体，并与墙保持这一距离 |
| `collision_mask` | 第 1 和第 3 层 | 阻挡相机臂的物体：`world` 和 `camera`。角色（第 2 层）不阻挡 |
| `ignored_groups` | `camera_ignore` | 这些分组中的物体，或属于这些分组的节点之下的物体，不阻挡相机臂 |
| `pull_in_on_occlusion` | 关 | 目标被遮挡时拉近 |
| `min_pull_in_length` | 2.5 米 | 因目标被遮挡而拉近时，相机不会比这更近；障碍物前方空间不足时，相机保持不动 |
| `pull_in_sharpness` | 10 | 相机移到遮挡障碍物前方的速度（0 表示立即）。遇到后方物体时总是立即停下 |
| `occlusion_points` | 胸部、头部、膝部、两侧 | 检查可见性的目标点，相对于相机臂起点：向右、向上、朝向相机 |
| `occlusion_share` | 0.75 | 当被遮挡的点达到这一比例时，视为目标被遮挡。细柱子或树干遮住五个点中的三个，不算遮挡 |
| `occlusion_delay` | 0.25 秒 | 目标需要持续被遮挡多久相机才拉近，以及需要持续可见多久相机才退回 |
| `return_delay`、`return_sharpness` | 0.3 秒、4 | 相机臂立即缩短，但会停顿片刻后再平滑伸长，因此相机在柱子之间不会抖动。返回途中遇到物体时直接越过，而不是穿过 |
| `fade_target` | — | 近距离时变为半透明的对象（演示中为 `Player/Visual`） |
| `fade_start_length`、`fade_end_length`、`fade_transparency` | 1.5 米、0.7 米、0.75 | 目标在第一个长度时开始淡化，在第二个长度时达到 75% 透明 |
| `debug_draw` | 关 | 绘制相机臂（灰色：滚轮设定的长度，绿色：当前长度）、相机球体以及到目标各点的射线（红色：被遮挡）。需从另一个相机观察 |

方法：`snap()`、`get_current_length()`、`is_pulled_in_by_occlusion()`。

### 仅阻挡相机的物体

将它们放在物理层 3（`camera`）上。角色不会与它们碰撞，点击和导航也看不到它们。房屋的屋顶（`shared/world/props/house.tscn` 中的 `RoofCameraBlocker`）就有这样一个物体：相机会在屋顶处停下，但没有人能爬上屋顶或寻路穿过它。

### `camera_ignore` 分组

该分组也对属于它的节点之下的所有内容生效。只需在道具场景的根节点上设置一次，这样关卡中的每个实例都会带有它；也可以设置在关卡中的文件夹节点上。演示不需要它：即使在最近的缩放下（离地 3 米），树干（最高 2.4 米）也低于相机。

### 相机臂如何区分障碍物后方有空间与身处物体内部

相机臂首先检查相机能否停在相机臂末端：球体在那里不接触任何物体（包括相机前方的障碍物），且末端不在某个物体内部。从相机射向目标的射线看不到其起点所在物体的表面，因此它找到的是相机前方障碍物的远侧表面。从该表面射向相机臂末端的射线会进入相机所在的物体，并且不会离开。如果中间有东西挡着，就从该表面朝相机投射球体，球体停在挡路物体的前面，并越过其他物体。相机臂只是擦过的柱子不会移动相机。

Jolt 不会报告球体在投射起点处就接触到的物体，也不会报告投射起点所在的网格物体（例如山）。因此，如果另一个物体紧贴在该表面后方（栅栏后面紧挨着悬崖），或者投射会从另一个物体内部开始（两片靠得很近的薄岩片，相机臂几乎沿着它们延伸），就会在更靠近目标的地方寻找空闲空间。

返回的路径也会检查。相机臂等待伸长时可能会转动，按它保持的长度，相机可能会落进墙里：这时相机会立即移到空闲的长度。如果相机和它要返回的位置之间有物体（相机原本在栅栏前方，现在栅栏后方有了空间），停顿之后相机会越过该物体，而不是从中穿过。

## 实测行为

来自 `tests/camera_checks.gd` 和 `tests/camera_arm_checks.gd`：

- 奔跑方向与相机成 90° 时的跟随：`follow_time` 为 0 时 0.17 秒转过 95%，演示的 1.1 用时 1.23 秒；为 10 时 2 秒后只转了 90° 中的 39°。站立时不转动。按住右键时不转动，松开后继续。
- 开启跟随（1.1 秒）时按住左键：前 0.2 秒相机保持不动（短促的点击不会移动它），之后在 1.25 秒内转过跟到奔跑方向身后所需 28.3° 中的 27.1°，而奔跑方向只变化 0.01°；设为“立即”时也是如此。鼠标移动 150 像素会使奔跑方向转动 25°，且新方向保持不变。关闭 `keep_aim_on_camera_turn` 时，角色在 1.25 秒内绕偏 77.6°。
- 倾角对齐：用滚轮降低的相机（向下 22.5°）在 `follow_time` 为 0.5 时平滑过渡到 55°，约 0.65 秒完成 95%；如果关闭了转向，相机不会随奔跑方向转动。89° 会被限制到相机的 80° 上限。开启跟随且倾角为 20° 时按住左键：倾角在 1.25 秒内从 80° 变为 22.5°（正趋向 20°），奔跑方向变化 0.01°。
- 相机臂：空旷处为完整长度；后方有悬崖时立即停下；朝悬崖走时，相机靠近且不进入悬崖；悬崖消失后，相机臂停顿片刻再平滑恢复。栅栏后面紧挨着悬崖：相机停在栅栏前方。紧贴相机背后的栅栏：相机移到栅栏前方。在相机等待返回的位置出现的栅栏：相机立即移到栅栏后方。位于相机和角色中间的栅栏：默认相机留在栅栏后方；开启拉近时平滑移到栅栏前方，且短暂遮挡不计。紧挨角色的栅栏：相机不会跳到角色背后。细柱子不计，擦过相机臂的柱子不会移动相机，`camera_ignore` 中的物体不会阻挡相机，近距离时角色呈半透明。在关卡中，树篱迷宫、山坡及其薄岩片、帐篷和山顶石块旁，相机不会进入它们内部。
