# 操作

> 本文是[英文原文](../en/controls.md)的翻译。两者不一致时，以英文版为准。

使用鼠标和键盘，不支持手柄。下文的大部分行为都可以在设置窗口（F10）中更改，见[设置](settings.md)。输入的内部工作原理：[输入](systems/input.md)。

| 输入 | 动作 |
|---|---|
| 左键点击地面 | 绕开障碍物跑到该点；地面上出现标记 |
| 按住左键 | 跟随光标奔跑；奔跑时光标隐藏 |
| 左键 + 右键，按下顺序不限 | 向相机所看方向奔跑。用鼠标转动相机，英雄随之转向。A / D 斜向前偏转。松开左键即停下 |
| 右键 + 鼠标 | 让相机绕英雄环绕旋转；之后光标回到原位 |
| 右键 + WASD | 相对相机移动，侧移或转向（见下文）。松开按键或右键即停下 |
| 鼠标滚轮 | 将相机降低并靠近英雄，或升高并拉远 |
| Shift | 按住时冲刺，或按一下切换（可在设置中选择）。开启疲劳时，冲刺持续到体力耗尽；体力条位于屏幕底部 |
| 空格 | 跳跃 |
| F10 | 设置（游戏暂停）；按 Esc 或 F10 关闭 |

## 点击还是按住

一次按下是点击还是按住，在 0.2 秒后判定。

- **点击**（提前松开）：英雄沿路径跑向按下时的位置，即使之后鼠标移动过也是如此，并在该处出现标记。松开时开始奔跑。英雄到达，或你改用按住或按键接管时，标记淡出。
- **按住**（按得更久）：英雄立即跟随光标奔跑，绝不会转向按下时的位置。

在判定之前，英雄继续做原来的事。

英雄如何响应按住的按键（设置 → 操作 → **按住左键**）：

- **直奔光标**（默认）：不搜索路径。英雄沿障碍物滑行，无论你指向坡道的哪里都能跑上去，松开时平稳停下。
- **沿路径前往该点**：英雄沿导航路径前往光标下的点。在高度变化处（坡道、平台）附近，路径可能在不同路线之间跳变。松开后，英雄继续跑到最后一个点。

按住按键期间相机若在转动（跟随模式），光标会随世界移动，停留在你瞄准的位置上，因此英雄保持航向。见设置 → 相机 → **相机转动时光标保持瞄准**。

## 配合右键的按键

WASD 只在按住右键时有效，否则不起作用。模式分别针对单独按住右键（**右键 + WASD**）和同时按住两键（**左键 + 右键 + A/D**）设置，每项都有**关闭**和两种变体：

| | 侧移 | 转向 / 斜向（默认） |
|---|---|---|
| 右键 + W | 向前，朝相机所看方向 | 相同 |
| 右键 + A / D | 向侧面移动，面朝前方 | 向左 / 右转身并朝那里走 |
| 右键 + S | 后退，面朝前方，速度较慢 | 转身走向相机 |
| 两个键（W + A、S + D…） | 斜向移动，面朝前方 | 斜向移动，面朝前进方向 |
| 左键 + 右键 + A / D | 斜向前，面朝前方 | 斜向前，面朝前进方向 |

斜向移动与直线移动一样快。后退默认慢 30%（3.85 米/秒，而不是 5.5；设置 → 操作 → **后退（S）减速**）。斜向后退只部分减速（侧移时 S + D：21%），横向移动完全不减速，因此减速只存在于侧移模式中。

停下后，英雄保持原来的朝向；点击或按住会让它重新面朝奔跑方向。

只按住右键而不按任何键，不会打断跑向点击位置的过程，因此可以在奔跑中转动相机。在按住右键和 W 的同时松开左键，英雄会改由按键控制继续行走，不会停下。设为**关闭**的模式也会从操作提示中移除对应的一行。

按键按物理位置绑定，因此在任何键盘布局上都位于 WASD 的位置。

## 相机

- **环绕：** 右键加鼠标。如果开启了设置 → 相机 → **右键可上下倾斜相机**（默认关闭），鼠标的垂直移动也会倾斜相机。
- **缩放：** 滚轮同时改变距离和倾角。低于中间位置后，相机会迅速趋于水平，便于看清前方。
- **跟随**（默认关闭）：设置 → 相机 → **相机随奔跑方向转动**和**对齐相机倾角**。按住右键时，以及按下左键后的前 0.2 秒内，相机不会跟随。
- **障碍物：** 相机遇到后方的山、墙或屋顶时停下。可选：障碍物遮住英雄时，相机拉近。在障碍物后，英雄显示为剪影。

详见：[相机](systems/camera.md)。

## 冲刺与跳跃

- **冲刺：** 按住 Shift 且英雄在移动时，速度提高到 1.5 倍。开启疲劳时，体力可持续 5 秒；耗尽后，英雄以正常速度奔跑，直到体力恢复到 30%，此时若仍按住 Shift，会自动再次冲刺。按住 Shift 站着不动不消耗体力。在切换模式下，按一下开启冲刺，再按一下关闭；英雄力竭时冲刺也会关闭。
- **跳跃：** 高 1 米。落地前不久按下的跳跃会在落地时触发；走出边缘后不久按下跳跃仍然有效。边缘防护不会阻止从边缘跳下。

详见：[移动](systems/locomotion.md)。
