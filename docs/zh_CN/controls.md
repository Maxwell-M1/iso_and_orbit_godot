# 操作

[← 文档目录](index.md)

> 本文是[英文原文](../en/controls.md)的翻译。两者不一致时，以英文版为准。

使用鼠标和键盘，不支持手柄。下文的大部分行为都可以在设置窗口（F10）中更改，见[设置](settings.md)。输入的内部工作原理：[输入](systems/input.md)。

本页及其他文档所写的按键与鼠标操作是演示在“项目设置 → 输入映射”中的默认绑定。游戏提示、设置窗口和加载画面会显示当前绑定的按键名称；更改绑定后，文字也会更新（见[文本中的按键名称](systems/ui.md#文本中的按键名称)）。

| 输入 | 动作 |
|---|---|
| 左键点击地面 | 绕开障碍物跑到该点；地面上出现标记 |
| 按住左键 | 跟随光标奔跑；奔跑时光标隐藏 |
| 按住左键，然后按右键 | 奔跑时环顾四周：鼠标转动相机，英雄保持原路线。松开右键后继续用鼠标引导 |
| 按住右键，然后按左键，或同时按两键 | 向相机所看方向奔跑。用鼠标转动相机，英雄随之转向。A / D 使路线斜向前偏转。松开左键即停下；也可以按任意顺序松开两键 |
| 右键 + 鼠标 | 让相机绕英雄环绕旋转；之后光标回到原位 |
| 右键 + WASD | 相对相机移动，侧移或转向（见下文）。松开按键或右键即停下 |
| 鼠标滚轮 | 将相机降低并靠近英雄，或升高并拉远 |
| Shift | 按住时冲刺，或按一下切换（可在设置中选择）。开启疲劳时，冲刺持续到体力耗尽；体力条位于屏幕底部 |
| 空格 | 跳跃 |
| E | 站在传送台上时：前往它指向的地点。点击旅行提示也一样 |
| F10 | 设置（游戏暂停）；按 Esc 或 F10 关闭 |

## 点击还是按住

一次按下是点击还是按住，在 0.2 秒后判定。

- **点击**（提前松开）：英雄沿路径跑向按下时的位置，即使之后鼠标移动过也是如此，并在该处出现标记。松开时开始奔跑。英雄到达，或你改用按住或按键接管时，标记淡出。
- **按住**（按得更久）：英雄立即跟随光标奔跑，绝不会转向按下时的位置。

在判定之前，英雄继续做原来的事。

英雄如何响应按住的按键（设置 → 操作 → **按住左键**）：

- **直奔光标**（默认）：不搜索路径。英雄沿障碍物滑行，无论你指向坡道的哪里都能跑上去，松开时平稳停下。
- **沿路径前往该点**：英雄沿导航路径前往光标下的点。在高度变化处（坡道、平台）附近，路径可能在不同路线之间跳变。松开后，英雄继续跑到最后一个点。

按住左键期间，如果相机自行转动（跟随模式），光标会随世界移动，停留在你瞄准的位置上，因此英雄保持航向。奔跑中按右键环顾四周时也一样。见设置 → 相机 → **相机转动时光标保持瞄准**。

## 两个鼠标键：按键顺序的影响

右键始终可以转动相机。它是否也会引导奔跑，取决于按键顺序。默认设置下：

| 你的操作 | 英雄 | 相机 |
|---|---|---|
| 按住左键 | 直奔光标 | 保持原位（默认关闭跟随） |
| ……接着也按右键并移动鼠标 | 保持原奔跑方向：环顾四周不会引导路线。此时方向键也不起作用 | 绕英雄旋转 |
| ……随后松开右键，仍按住左键 | 保持原方向。隐藏的光标仍指向先前瞄准处，从那里继续受鼠标引导 | 停在松手时的方向 |
| ……或者先松开左键 | 平稳停下；松开右键时，光标出现在瞄准处 | 在松开右键前仍可环绕 |
| 先按右键再按左键，或在 0.2 秒内同时按下 | 向相机所看方向奔跑，随相机转向；A / D 斜向前偏转 | 随鼠标转动 |
| ……随后松开右键，仍按住左键 | 保持相机原来的方向，直到移动鼠标；随后位于英雄前方 4 米的光标开始引导 | 停在松手时的方向 |
| ……还没移动鼠标就再次按右键 | 再次朝相机方向奔跑。一旦鼠标移动、光标开始引导，右键就改为环顾四周 | 随鼠标转动 |
| 松开左键 | 约四分之一秒内平稳停下。如果右键和 W 仍按着，则改由按键控制继续行走 | — |
| 以任意顺序、任意间隔松开两键，期间没有移动鼠标 | 沿当前方向停下，不会转向光标 | — |
| 点击后再按右键 | 继续跑向点击的地点 | 绕英雄旋转 |
| 按右键并使用 WASD | 相对相机行走，转身面朝前进方向 | 随鼠标转动 |

如果想在不停下的情况下，从环顾四周切换为朝相机方向奔跑，可按住右键并再次按下左键。

### 设置如何改变行为

- **按住左键奔跑时，右键只旋转相机**（操作）关闭后：不论按键顺序，右键都会引导奔跑。在跟随光标奔跑时按右键，英雄会立刻转向相机所看方向。
- **相机转动时光标保持瞄准**（相机）关闭后：环顾四周时，光标固定在屏幕上，奔跑路线会随相机沿弧线转动。相机自动跟随奔跑时也会产生同样效果。
- **按住左键 → 沿路径前往该点**（操作）：英雄沿路径跑向光标下方。在环顾四周期间，以及其后直到再次移动鼠标，目标点相对英雄保持不变，而不是一直在光标下；从另一角度看，光标可能正处于坡道或平台上。松开左键后，英雄继续跑向最后的目标点。
- **按住左键奔跑时隐藏光标**（操作）关闭后：环顾四周结束，光标会从先前位置跳到当前瞄准位置；该位置在相机转动时已在屏幕上移动。
- **相机随奔跑方向转动**、**奔跑时对齐相机倾角**、**奔跑时对齐相机高度**（相机）：相机会平滑转到光标引导或点击目标的奔跑后方，但按住右键时不会跟随。用右键转动相机后，包括奔跑中环顾四周，相机会保持你留下的视角，直到英雄停下，或用左键开始新的奔跑（点击新目标或重新按住）。按键行走从不触发跟随，因为它需要右键。
- **右键 + WASD** 和 **左键 + 右键 + A/D**（操作）：决定按键如何移动英雄，见下文。

## 配合右键的按键

WASD 只在按住右键时有效，否则不起作用。模式分别针对单独按住右键（**右键 + WASD**）和同时按住两键（**左键 + 右键 + A/D**）设置，每项都有**关闭**和两种变体：

| | 侧移 | 转向 / 斜向（默认） |
|---|---|---|
| 右键 + W | 向前，朝相机所看方向 | 相同 |
| 右键 + A / D | 向侧面移动，面朝前方 | 向左 / 右转身并朝那里走 |
| 右键 + S | 后退，面朝前方，速度较慢 | 转身走向相机 |
| 两个键（W + A、S + D…） | 斜向移动，面朝前方 | 斜向移动，面朝前进方向 |
| 左键 + 右键 + A / D | 斜向前，面朝前方 | 斜向前，面朝前进方向 |

斜向移动与直线移动一样快。后退默认慢 30%（3.85 米/秒，而不是 5.5；设置 → 操作 → **后退（S）减速**）。斜向后退只部分减速（侧移时 S + D：21%），横向移动完全不减速，因此减速只存在于侧移模式中。

停下后，英雄保持原来的朝向；点击或按住会让它重新面朝奔跑方向。

设为**关闭**的模式也会从操作提示中移除对应的一行。鼠标键与方向键组合的细节见[两个鼠标键：按键顺序的影响](#两个鼠标键按键顺序的影响)。

移动键使用美式 QWERTY 键盘上 WASD 的物理位置。显示的字母会随键盘布局变化，例如 AZERTY 键盘相同位置是 ZQSD。可在“项目设置 → 输入映射”中修改绑定；演示尚无游戏内重新绑定菜单。

## 相机

- **环绕：** 右键加鼠标。如果开启了设置 → 相机 → **右键可上下倾斜相机**（默认关闭），鼠标的垂直移动也会倾斜相机。
- **缩放：** 滚轮同时改变距离和倾角。低于中间位置后，相机会迅速趋于水平，便于看清前方。
- **跟随**（默认关闭）：设置 → 相机 → **相机随奔跑方向转动**、**奔跑时对齐相机倾角**和**奔跑时对齐相机高度**。按住右键时，以及按下左键后的前 0.2 秒内，相机不会跟随。用右键转动相机后，包括奔跑中环顾四周，相机保持选定视角，直到英雄停下或用左键开始新的奔跑（点击或按住）；角色制动或继续奔向已点击地点时不会突然绕转。方向键需要右键，因此按键行走从不触发跟随。
- **障碍物：** 相机遇到后方的山、墙或屋顶时停下。可选：障碍物遮住英雄时，相机拉近。在障碍物后，英雄显示为剪影。

详见：[相机](systems/camera.md)。

## 传送

远古石环旁的发光传送台通往孤岛，岛上也有返回的传送台。站上去，屏幕底部会出现“E 传送至……”提示；走开后提示消失。按 E（冲刺跑上去时同时按着 Shift 也可以），或点击提示：加载画面会遮住切换过程，英雄抵达另一座传送台旁，相机转到身后，操控恢复。跨越切换一直按住的左键须重新按下才算新的操作；仍按着的其他键（右键加 W、A、S 或 D，或 Shift）会立即再次生效。详见[关卡](systems/levels.md)。

## 冲刺与跳跃

- **冲刺：** 按住 Shift 且英雄在移动时，速度提高到 1.5 倍。开启疲劳时，体力可持续 5 秒；耗尽后，英雄以正常速度奔跑，直到体力恢复到 30%，此时若仍按住 Shift，会自动再次冲刺。按住 Shift 站着不动不消耗体力。在切换模式下，按一下开启冲刺，再按一下关闭；英雄力竭时冲刺也会关闭。
- **跳跃：** 高 1 米。落地前不久按下的跳跃会在落地时触发；走出边缘后不久按下跳跃仍然有效。边缘防护不会阻止从边缘跳下。

详见：[移动](systems/locomotion.md)。
