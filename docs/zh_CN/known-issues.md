# 已知问题

> 本文是[英文原文](../en/known-issues.md)的翻译。两者不一致时，以英文版为准。

项目的局限，以及项目所规避的引擎怪癖。每一条都说明你会看到什么以及该怎么做。

## 局限

- **仅支持鼠标和键盘。** 不支持手柄。
- **没有动画。** 模型是静态的基本几何体；只有手持物品会随脚步摆动（`HandSway`）。`NavigationMover.get_speed()` 和 `GroundCharacter.get_step_phase()` 可用于驱动 `AnimationTree`。
- **角色之间没有避让。** `NavigationMover` 沿路径移动，不使用导航避障，因此移动中的角色不会互相绕开。玩家身体位于第 2 层，只与第 1 层碰撞，因此由 `player.tscn` 制作的两个角色会互相穿过；如果它们应当互相阻挡，请将第 2 层加入它们的 `collision_mask`。演示中的 NPC 站着不动，作为障碍物烘焙进了导航网格。
- **导航网格是预先烘焙的。** 在运行时移动障碍物不会改变路径。编辑关卡后，请重新烘焙网格（[世界与导航](systems/world-and-navigation.md#重新烘焙导航网格)）。
- **仅支持 Godot 4.7。** 项目在 4.7.2 上测试。剪影需要模板缓冲区（4.5+），而场景警告检查复现的是 4.7.2 的判定条件。

## 输入

- **点击在松开时生效。** 按下只有在 0.2 秒后（`hold_delay`）或松开时才会被判定为点击或按住，因此点击比按下即生效晚约 0.1 秒。这是有意为之：否则按住时英雄会先沿路径跑向按下的位置。见[输入](systems/input.md#点击还是按住)。
- **在某些系统上光标可能无法保持瞄准。** 相机转动时保持瞄准需要移动系统光标（`Viewport.warp_mouse()`）。在不允许这样做的系统上（例如 Wayland），奔跑方向依然保持，但光标停留在屏幕上原来的位置。
- **“沿路径前往该点”可能切换路线。** 在这种按住模式下，路径会随光标下的点移动而重建，在高度变化处（坡道、平台）附近可能从一条路线跳到另一条。默认模式“直奔光标”没有这个问题。
- **游戏在编辑器内运行时 Shift 可能卡住。** 当游戏嵌入编辑器的“游戏”选项卡（Game）且焦点移到编辑器时，引擎不会重置已按下的按键。只要冲刺动作绑定在修饰键上，`CharacterActionInput` 就会在下一个鼠标或键盘事件时释放卡住的冲刺。如果 Windows 粘滞键被开启（连续按五次 Shift），Shift 会在系统层面卡住；请在 Windows 设置中关闭粘滞键。见[输入](systems/input.md#shift-不会卡住)。

## 相机

- **紧贴障碍物后方的物体。** Jolt 不会报告形状投射在起点处就接触到的物体。当另一个物体紧贴在相机所处的障碍物后方时（栅栏后面紧挨着悬崖），相机臂会改为在更靠近目标的地方寻找空闲空间。见[相机](systems/camera.md#相机臂如何区分障碍物后方有空间与身处物体内部)。
- **关闭物理插值时运动有跳跃感。** 物理插值默认开启。关闭后（设置 → 显示），角色和相机逐个物理帧移动，每秒 60 次：在高刷新率显示器上看起来不够平滑，相机跟随奔跑转向时，角色在转弯时会晃动。

## 测试

- **罕见的 Jolt 警告导致运行失败。** 在 CPU 负载很高时，例如刚完成全新导入后的首次运行，Jolt Physics 可能打印“Jolt Physics job system exceeded the maximum number of jobs. This should not happen.”。测试运行器把每条引擎警告和错误都计为失败，因此即使所有检查都通过，运行也会以退出码 1 和“engine and script errors: 1”结束。该警告来自引擎的物理作业系统，而不是项目：请在空闲的机器上重新运行测试。

## 渲染

- **剪影使用了引擎的实验性功能。** 模板缓冲区在 Godot 4.5+ 中是实验性功能，且只能在透明通道中读取。如果将来的引擎版本对其做出更改，应首先检查剪影。
- **Godot 4.7 中投影在 Y 方向上是翻转的**（D3D12 和 Vulkan）：着色器中的 `PROJECTION_MATRIX[1][1]` 为负。剪影描边对它取 `abs()`；否则描边网格会收缩，描边随之消失。

## 项目文件

- **经过舍入的旋转会产生“non-uniform scale”（非均匀缩放）警告。** 以 4 位数字写入 `.tscn` 的旋转会使基向量的轴长相差超过 1e-5，引擎会对物体和形状报告非均匀缩放。请以完整精度（9 位有效数字）写入 `Transform3D` 的数值。
- **`shared/` 尚未完全与脚本语言无关。** `world.tscn` 和 `mountain.tscn` 使用了 `addons/iso_orbit/points_of_interest/point_of_interest.gd`，另有两个小型道具脚本位于 `shared/world/props/`。C# 版本将需要自己的地点脚本，或者一种仅用场景标记地点的方式。
- **退出时报告资源泄漏。** 如果脚本在脚步声播放后立即退出，引擎可能会报告泄漏的 `AudioStreamPlayback` 对象：使用 `--fixed-fps` 时，游戏时间跑在现实时间前面，而声音仍在播放。请先释放场景，稍等片刻再退出；`tests/run_checks.gd` 会等待 0.1 秒。
