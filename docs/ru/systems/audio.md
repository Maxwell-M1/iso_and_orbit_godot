# Звук

> Это перевод [английского оригинала](../../en/systems/audio.md). При расхождениях верен оригинал.

`GroundCharacter` сообщает о том, что с ним происходит, сигналами: `stepped(sprinting)`, `jumped`,
`landed(impact_speed)`, `sprint_changed(sprinting)` (см. [Передвижение](locomotion.md#сигналы)). К ним подключаются
звуки, пыль из-под ног или анимации; сам персонаж о них ничего не знает. Демо подключает звуки.

## CharacterSounds

`CharacterSounds` (`Player/Sounds`) — дочерний `Node3D` персонажа. Его потомки — узлы `AudioStreamPlayer3D`, поэтому
звук идёт от персонажа и для NPC работает так же. Без этого узла персонаж работает точно так же, только беззвучно.

| Звук | Плеер | Что звучит |
|---|---|---|
| Шаги | `Footsteps` | `AudioStreamRandomizer` из четырёх вариантов со случайной высотой (±8%) и громкостью, до трёх одновременно. При ускорении чуть выше (`sprint_step_pitch` 1,08) и громче (+2 дБ); чаще — сами собой, раз шаги идут по расстоянию |
| Прыжок | `Jump` | Толчок ногой и шорох одежды |
| Приземление | `Land` | Тяжёлый глухой удар, тем громче, чем быстрее падение: полная громкость начиная с `land_full_speed` (10 м/с), никогда не тише `min_land_volume` (30%) |
| Рывок | `SprintStart` | Толчок и нарастающий порыв воздуха в начале ускорения |
| Бег с ускорением | `SprintLoop` | Двухсекундная петля частого дыхания и воздуха, плавно появляется и затихает за `sprint_loop_fade` (0,25 с) |

| Свойство | По умолчанию | Описание |
|---|---|---|
| `character` | родитель | Чьи сигналы озвучивать |
| `footsteps`, `jump`, `land`, `sprint_start`, `sprint_loop` | — | Плееры |
| `footsteps_enabled`, `jump_enabled`, `sprint_enabled` | вкл | Группы звуков; группа прыжка охватывает прыжок и приземление, группа ускорения — рывок и петлю |
| `sprint_step_pitch`, `sprint_step_volume_db` | 1,08; +2 дБ | Шаги при ускорении |
| `land_full_speed`, `min_land_volume` | 10 м/с; 0,3 | Кривая громкости приземления |
| `sprint_loop_fade` | 0,25 с | Нарастание и затухание петли ускорения |

Громкость задана на плеерах в `gdscript/player/player.tscn`; подстраивайте её в запущенной игре через удалённое
дерево (Remote). Исключение — `Land`: его громкость выставляется перед каждым приземлением по скорости падения
(`land_full_speed`, `min_land_volume`). Группы переключаются в Настройки → Звук; звуки ускорения демо по умолчанию
выключает. Общая громкость там — это шина `Master`: процент — доля амплитуды (50% — на 6 дБ тише), 0 заглушает
шину.

## Сами звуки

Файлы в `shared/audio/character/` синтезированы скриптом: глухие удары — синусоиды с падающей высотой, хруст и
воздух — шум через полосовые фильтры. Петля ускорения содержит в WAV чанк `smpl`, и режим зацикливания при импорте
по умолчанию, «Detect From WAV», зацикливает её без правки настроек импорта. Шов петли сведён кроссфейдом конца в
начало, поэтому не щёлкает.

Их можно заменить настоящими записанными звуками: положите в папку файлы с теми же именами.
