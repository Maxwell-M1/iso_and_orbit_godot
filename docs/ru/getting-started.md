# Начало работы

[← Оглавление документации](index.md)

> Это перевод [английского оригинала](../en/getting-started.md). При расхождениях верен оригинал.

## Требования

- Godot 4.7.2. Обычной сборки достаточно: проект написан на GDScript и не требует .NET SDK.
- Для демо больше ничего не нужно: Jolt Physics встроен в движок, рендерер — Forward+, а все ассеты лежат в
  репозитории.

## Открытие и запуск

1. Клонируйте репозиторий.
2. В менеджере проектов (Project Manager) нажмите **Импорт** (Import) и выберите `project.godot`, затем откройте
   проект. Первый импорт займёт некоторое время: кэша `.godot/` в репозитории нет.
3. Нажмите F5. Главная сцена — `res://gdscript/main.tscn`.

Демо загружает ваши прежние сохранённые настройки. Для значений по умолчанию, описанных здесь, используйте
**F10 → Сбросить всё**. В свежем клоне дождитесь окончания импорта, прежде чем открывать скрипты или запускать
тесты. Не копируйте кэш `.godot/` из другого проекта.

## Что вы увидите

Герой стоит в точке появления посреди обнесённой забором поляны. В левом верхнем углу перечислено управление, в
правом верхнем — частота кадров.

- **Щелчок левой кнопкой** по земле: герой бежит туда, огибая препятствия, а метка показывает точку.
- **Зажатая левая кнопка**: герой бежит за курсором.
- **Правая кнопка + мышь**: вращение камеры. **Колесо**: зум.
- **Сначала правая кнопка, затем левая**: бег туда, куда смотрит камера. **Зажатая левая, затем правая**:
  осмотр во время бега. **Правая кнопка + WASD**: движение относительно камеры.
- **Shift** — ускорение, **Пробел** — прыжок, **F10** открывает настройки.

Полный список — на странице [Управление](controls.md).

Куда сходить:

- **Древний круг** — кольцо колонн к северо-западу от точки появления. Пройдите между колоннами: за ними герой виден
  силуэтом.
- **Лагерь путников** на востоке и **Хутор у колодца** на юго-западе, с NPC.
- **Вершина ветров** — гора на северо-востоке: щёлкните по её вершине, и герой поднимется по спиральной тропе.
- Лабиринт из живой изгороди, платформа с пандусом и лестницей и П-образная ловушка рядом с точкой появления — для
  проверки поиска пути.
- Десять обликов героя в ряд у южной стены. Выберите один в Настройки → Персонаж → **Облик героя**.
- **Площадка телепортации** у Древнего круга с вращающимся кристаллом: встаньте на неё и нажмите E или щёлкните
  по приглашению, чтобы попасть на **Одинокий остров** в **Лагерь отшельника**. Площадка на острове
  («Телепорт: Зелёная долина») возвращает обратно.

## Настройки

F10 открывает окно настроек и ставит игру на паузу; Esc или F10 закрывает его. Настройки сохраняются в
`user://settings.cfg` и применяются сразу. Чтобы скрыть подсказку по управлению, выключите Настройки → Интерфейс →
**Подсказка по управлению и скорость**. На той же вкладке выбирается язык интерфейса. Все настройки:
[Настройки](settings.md).

## Запуск тестов

```bash
godot --headless --fixed-fps 60 --path . --script res://tests/run_checks.gd
```

Здесь `godot` — исполняемый файл Godot 4.7.2. В Windows используйте сборку `_console.exe`, чтобы видеть вывод и
получить код возврата. В свежем клоне сначала один раз импортируйте проект — в редакторе или командой
`godot --headless --path . --import`. Подробнее: [Тесты](testing.md).
