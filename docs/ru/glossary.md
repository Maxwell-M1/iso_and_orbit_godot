# Глоссарий

> Это перевод [английского оригинала](../en/glossary.md). При расхождениях верен оригинал.

Термины в том значении, в каком их используют эта документация и код.

| Термин | Значение |
|---|---|
| **Радиус агента** (agent radius) | Насколько навигационная сетка отступает от препятствий: 0,5 м — больше, чем капсула персонажа в 0,35 м, поэтому пути идут с запасом от углов |
| **Держатель камеры** (arm) | `CameraArm`: узел, который держит камеру на конце линии от цели. Колесо задаёт его длину, препятствия его укорачивают |
| **Тело только для камеры** (camera-only body) | Тело на физическом слое 3 (`camera`): оно останавливает держатель камеры, но щелчки, навигация и персонажи его игнорируют |
| **Щелчок** (click) | Нажатие левой кнопки, отпущенной раньше, чем истекла задержка удержания. Персонаж бежит по пути к точке, где была нажата кнопка |
| **Время койота** (coyote time) | Короткое время после схода с края, когда прыжок ещё срабатывает (0,1 с) |
| **Без сил** (exhausted) | Состояние после того, как силы кончились: ускорения нет, пока запас сил не восстановится до `recover_ratio` (30%) |
| **Взгляд** (facing) | Куда смотрит персонаж, в отличие от того, куда он движется. Они различаются при движении боком и назад. `NavigationMover.get_facing()` |
| **Следование** (follow) | Камера сама разворачивается за бегущим персонажем и, по выбору, плавно выравнивает наклон (`follow_movement`, `follow_pitch`) |
| **Направление движения** (heading) | Направление, в котором движется персонаж. `NavigationMover.get_heading()` |
| **Облик героя** (hero look) | Одна из десяти моделей, которые может носить персонаж игрока; выбирается по номеру в настройках (`CharacterAppearance`) |
| **Удержание** (hold) | Левая кнопка, зажатая дольше задержки удержания. Персонаж бежит за курсором |
| **Задержка удержания** (hold delay) | Время, по которому щелчок отличается от удержания: 0,2 с (`PointClickMoveInput.hold_delay`) |
| **Буфер прыжка** (jump buffer) | Прыжок, нажатый незадолго до приземления, запоминается и срабатывает при приземлении (0,12 с) |
| **Курсор держит цель** (keeping the aim) | Системный курсор движется вместе с миром, пока кнопка зажата и камера поворачивается, так что он остаётся над той же точкой земли (`keep_aim_on_camera_turn`) |
| **Защита от обрывов** (ledge guard) | `LedgeGuard`: останавливает персонажа у обрыва выше 0,5 м или ведёт его вдоль края |
| **Облик** (look) | См. «облик героя» |
| **Метка** (marker) | `ClickMarker`: кольцо на земле в точке щелчка |
| **Контроллер перемещения** (mover) | `NavigationMover`: каждый тик превращает команды (`move_to`, `steer`, `stop`) в горизонтальную скорость. Тело он никогда не двигает |
| **Навигационная сетка** (navigation mesh) | Проходимая область, запечённая по столкновениям уровня на слое 1 и хранящаяся в `world.tscn`. По ней ищутся пути |
| **Интерполяция физики** (physics interpolation) | Отрисовка тел между физическими тиками с частотой кадров экрана. По умолчанию включена, выключается настройкой |
| **Наклон** (pitch, tilt) | Насколько круто камера смотрит вниз. В коде — отрицательные углы, в настройках — градусы вниз |
| **Разворот на месте** (pivot) | Мгновенный поворот из состояния покоя, на скорости ниже `pivot_speed` (1 м/с) |
| **Место** (place) | `PointOfInterest`: область, которая показывает «Открыто место: …», когда игрок впервые в неё входит |
| **Приближение** (pull-in) | Камера подходит ближе препятствия, которое закрывает персонажа (`pull_in_on_occlusion`) |
| **Боком** (sidestep) | Режим клавиш с правой кнопкой: персонаж смотрит туда же, куда камера, и при этом движется вбок или назад |
| **Силуэт** (silhouette) | Персонаж, нарисованный плоской фигурой с обводкой там, где его что-то закрывает (`OccludedSilhouette`) |
| **Ускорение** (sprint) | Бег быстрее (×1,5), пока Shift зажат или включён переключением; тратит запас сил |
| **Запас сил** (stamina) | Резерв для ускорения (`Stamina`): тратится во время ускорения, восстанавливается после паузы |
| **Бег по направлению** (steer) | Бег в направлении без пути: `NavigationMover.steer()`. При удержании кнопки персонаж по умолчанию бежит так к курсору |
| **Тик** (tick) | Один шаг физики; 60 в секунду |
| **С поворотом** (turn mode) | Режим клавиш с правой кнопкой: персонаж поворачивается лицом по ходу движения |
| **Поворот камеры** (yaw) | Направление камеры вокруг вертикальной оси |
| **Зум** (zoom) | Значение от 0 (ближе всего) до 1 (дальше всего), которое задаёт расстояние и наклон камеры вместе |
