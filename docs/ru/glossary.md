# Глоссарий

[← Оглавление документации](index.md)

> Это перевод [английского оригинала](../en/glossary.md). При расхождениях верен оригинал.

Термины в том значении, в каком их используют эта документация и код.

| Термин | Значение |
|---|---|
| **Радиус агента** (agent radius) | Насколько навигационная сетка отступает от препятствий: 0,5 м — больше, чем капсула персонажа в 0,35 м, поэтому пути идут с запасом от углов |
| **Держатель камеры** (arm) | `CameraArm`: узел, который держит камеру на конце линии от цели. Колесо задаёт его длину, препятствия его укорачивают |
| **Смешивание** (blend) | `GroundCharacter.get_locomotion_blend()`: скорость в виде числа для анимаций; 0 — на месте, 1 — бег, 2 — бег с ускорением |
| **Границы уровня** (bounds) | Физический слой 4: невидимые стены у края уровня. Персонажи сталкиваются с ними, щелчки и держатель камеры проходят сквозь них |
| **Тело только для камеры** (camera-only body) | Тело на физическом слое 3 (`camera`): оно останавливает держатель камеры, но щелчки, навигация и персонажи его игнорируют |
| **Состояние персонажа** (character state) | Что делает персонаж: стоит, бежит, бежит с ускорением, прыгает или падает (`GroundCharacter.get_state()`, сигнал `state_changed`) |
| **Щелчок** (click) | Нажатие левой кнопки, отпущенной раньше, чем истекла задержка удержания. Персонаж бежит по пути к точке, где была нажата кнопка |
| **Время койота** (coyote time) | Короткое время после схода с края, когда прыжок ещё срабатывает (0,1 с) |
| **Без сил** (exhausted) | Состояние после того, как силы кончились: ускорения нет, пока запас сил не восстановится до `recover_ratio` (30%) |
| **Взгляд** (facing) | Куда смотрит персонаж, в отличие от того, куда он движется. Они различаются при движении боком и назад. `NavigationMover.get_facing()` |
| **Настройки падения** (fall settings) | Спуск после верхней точки прыжка или схода с края: гравитация падения, предельная скорость и торможение до неё (`FallSettings`). Подъём при прыжке от них не зависит |
| **Парение** (floating) | Модель висит над землёй и плавно проходит ступени, а тело движется как прежде (`CharacterHover`). При парении шаги не считаются; в демо спуск замедлен |
| **Следование** (follow) | Камера сама поворачивается за бегом и приводит наклон и высоту к заданным значениям; каждое движение плавно начинается и заканчивается (`follow_movement`, `follow_pitch`, `follow_zoom`). После вращения может ждать остановки или нового бега (`follow_wait_after_rotate`, в демо включён) |
| **Цикл походки** (gait cycle) | Два шага, левый и правый, в виде числа от 0 до 1 (`GroundCharacter.get_gait_cycle()`). Идёт по пройденному расстоянию, а не по времени |
| **Направление движения** (heading) | Направление, в котором движется персонаж. `NavigationMover.get_heading()` |
| **Облик героя** (hero look) | Одна из десяти моделей, которые может носить персонаж игрока; выбирается по номеру в настройках (`CharacterAppearance`) |
| **Удержание** (hold) | Левая кнопка, зажатая дольше задержки удержания. Персонаж бежит за курсором |
| **Задержка удержания** (hold delay) | Время, по которому щелчок отличается от удержания: 0,2 с (`PointClickMoveInput.hold_delay`) |
| **Буфер прыжка** (jump buffer) | Прыжок, нажатый незадолго до приземления, запоминается и срабатывает при приземлении (0,12 с) |
| **Курсор держит цель** (keeping the aim) | Системный курсор движется вместе с миром, пока кнопка зажата и камера поворачивается, так что он остаётся над той же точкой земли (`keep_aim_on_camera_turn`) |
| **Защита от обрывов** (ledge guard) | `LedgeGuard`: останавливает персонажа у обрыва выше 0,5 м или ведёт его вдоль края |
| **Хост уровней** (level host) | `LevelHost`: узел текущего уровня, который меняет его за экраном загрузки. Герой и интерфейс — соседи хоста, а не части уровня |
| **Экран загрузки** (loading screen) | `LoadingScreen`: экран над игрой при смене уровня, с размытым последним кадром, названием места, шкалой и подсказками |
| **Облик** (look) | См. «облик героя» |
| **Осмотр во время бега** (looking around) | Правая кнопка, нажатая во время бега за курсором: мышь поворачивает только камеру, герой сохраняет курс (`look_around_while_held`). Если сначала нажать правую, бег пойдёт по направлению камеры |
| **Метка** (marker) | `ClickMarker`: кольцо на земле в точке щелчка |
| **Контроллер перемещения** (mover) | `NavigationMover`: каждый тик превращает команды (`move_to`, `steer`, `stop`) в горизонтальную скорость. Тело он никогда не двигает |
| **Навигационная сетка** (navigation mesh) | Проходимая область, запечённая по коллизиям уровня на слое 1 (на острове также по невидимым стенам слоя 4) и сохранённая в сцене каждого уровня. По ней ищутся пути |
| **Приглашение к переходу** (offer to travel) | `TravelPrompt`: значок клавиши и «Телепорт: …» на экране, пока герой стоит в портале с подтверждением, например на площадке. E (действие `interact`) или щелчок запускают переход; при уходе приглашение скрывается |
| **Интерполяция физики** (physics interpolation) | Отрисовка тел между физическими тиками с частотой кадров экрана. По умолчанию включена, выключается настройкой |
| **Наклон** (pitch, tilt) | Насколько круто камера смотрит вниз. В коде — отрицательные углы, в настройках — градусы вниз |
| **Разворот на месте** (pivot) | Мгновенный поворот из состояния покоя, на скорости ниже `pivot_speed` (1 м/с) |
| **Место** (place) | `PointOfInterest`: область, которая показывает «Открыто место: …», когда игрок впервые в неё входит |
| **Игровой герой** (playable hero) | `PlayableHero` (`playable_hero.tscn`): управляемый герой с вводом, камерой, маркером щелчка и линией пути; стоит в игровой сцене рядом с уровнями |
| **Портал** (portal) | `LevelPortal`: область, ведущая на другой уровень; площадки телепортации в демо — порталы |
| **Приближение** (pull-in) | Камера подходит ближе препятствия, которое закрывает персонажа (`pull_in_on_occlusion`) |
| **Резкий поворот** (sharp turn) | Поворот бега быстрее `OrbitCameraRig.sharp_turn_speed` (360°/с), например разворот: камера не следует за промежуточными направлениями, а после поворота принимает новое |
| **Оболочка игры** (shell) | Сцена, остающаяся во время игры (`main.tscn` с `main.gd`): хост уровней, герой, интерфейс и экран загрузки |
| **Боком** (sidestep) | Режим клавиш с правой кнопкой: персонаж смотрит туда же, куда камера, и при этом движется вбок или назад |
| **Силуэт** (silhouette) | Персонаж, нарисованный плоской фигурой с обводкой там, где его что-то закрывает (`OccludedSilhouette`) |
| **Точка появления** (spawn point) | `SpawnPoint`: именованное место появления персонажа на уровне; каждому уровню нужна точка `default` |
| **Ускорение** (sprint) | Бег быстрее (×1,5), пока Shift зажат или включён переключением; тратит запас сил |
| **Высота ступени** (stair height) | Самая высокая ступень, на которую персонаж шагает без прыжка: 0,3 м (`GroundCharacter.max_step_height`) |
| **Запас сил** (stamina) | Резерв для ускорения (`Stamina`): тратится во время ускорения, восстанавливается после паузы |
| **Начальный уровень** (start level) | Уровень, помещённый под хостом в редакторе: `shared/world/world.tscn`, обнесённый забором луг. В игре он называется Зелёной долиной (название на площадке острова) |
| **Бег по направлению** (steer) | Бег в направлении без пути: `NavigationMover.steer()`. При удержании кнопки персонаж по умолчанию бежит так к курсору |
| **Телепортация** (teleport) | Мгновенный перенос персонажа без бега и рывка: `GroundCharacter.teleport()`, `PlayableHero.teleport()` |
| **Тик** (tick) | Один шаг физики; 60 в секунду |
| **Путешественник** (traveller) | Тело, которое может воспользоваться порталом: состоит в его группе `traveller_group` (по умолчанию `player`) |
| **С поворотом** (turn mode) | Режим клавиш с правой кнопкой: персонаж поворачивается лицом по ходу движения |
| **Прогрев** (warm-up) | Кадры нового уровня, которые хост рисует за экраном загрузки до его исчезновения, чтобы шейдеры успели скомпилироваться и персонаж встал на землю (`LevelHost.warmup_frames`, 3) |
| **Поворот камеры** (yaw) | Направление камеры вокруг вертикальной оси |
| **Зум** (zoom) | Значение от 0 (ближе всего) до 1 (дальше всего), которое задаёт расстояние и наклон камеры вместе |
