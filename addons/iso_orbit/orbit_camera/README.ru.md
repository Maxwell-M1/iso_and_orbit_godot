# Орбитальная камера

[English](README.md) · [Español](README.es.md) · [日本語](README.ja.md) · [Português (Brasil)](README.pt_BR.md) · **Русский** · [Türkçe](README.tr.md) · [简体中文](README.zh_CN.md)

> Это перевод [английского оригинала](README.md). При расхождениях верен оригинал.

Орбитальная камера для изометрических игр и игр с видом сверху: следует за целью, вращается правой кнопкой мыши,
меняет зум колесом (расстояние и наклон меняются вместе) и может сама разворачиваться за бегущей целью. Камера сидит
на конце держателя, который упирается в стены позади и может подходить ближе, когда препятствие закрывает цель.

Часть Iso & Orbit — шаблона камеры и контроллера персонажа для Godot 4.7. Лицензия MIT (см. `LICENSE`).

## Состав

| Файл | Класс | Назначение |
|---|---|---|
| `orbit_camera_rig.gd` | `OrbitCameraRig` (Node3D) | Следование за целью, вращение, зум, режим следования |
| `camera_arm.gd` | `CameraArm` (Node3D) | Держит камеру и укорачивается у препятствий; вблизи делает цель полупрозрачной |

Другие аддоны не нужны.

## Настройка

1. Скопируйте эту папку в `res://addons/iso_orbit/orbit_camera/`.
2. Добавьте действия ввода (их имена — экспортируемые свойства, так что можно использовать свои): `camera_rotate`
   (правая кнопка мыши), `camera_zoom_in` (колесо вверх), `camera_zoom_out` (колесо вниз).
3. Соберите камеру рядом с целью, а не внутри неё:

   ```
   CameraRig    Node3D с orbit_camera_rig.gd, target = ваш персонаж
   └── CameraArm    Node3D с camera_arm.gd
       └── Camera3D
   ```

4. Физические слои: держатель камеры упирается в тела на слоях 1 и 3 (`collision_mask`). Поместите геометрию уровня на
   один из них, а персонажей на них не помещайте. Тела в группе `camera_ignore` (или под узлом из неё) никогда не
   останавливают держатель.
5. Если цель движется в физических тиках, включите в проекте интерполяцию физики: риг камеры следует за
   интерполированной позицией цели.

Без держателя тоже можно — с `Camera3D` прямо в качестве дочернего узла рига камеры: она стоит на расстоянии, заданном
зумом, и проходит сквозь стены.
