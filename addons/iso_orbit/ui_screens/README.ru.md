# Окна интерфейса

[English](README.md) · [Español](README.es.md) · [日本語](README.ja.md) · [Português (Brasil)](README.pt_BR.md) · **Русский** · [Türkçe](README.tr.md) · [简体中文](README.zh_CN.md)

> Это перевод [английского оригинала](README.md). При расхождениях верен оригинал.

Окна поверх игры в виде стека: открывайте одно поверх другого, закрывайте верхнее по Esc; пока открыто хоть одно
окно, игра стоит на паузе и курсор мыши виден; фокус клавиатуры переходит в окно и возвращается обратно, когда окно
закрывается. А также счётчик FPS, который продолжает работать, пока игра на паузе.

Часть Iso & Orbit — шаблона камеры и контроллера персонажа для Godot 4.7. Лицензия MIT (см. `LICENSE`).

## Состав

| Файл | Класс | Назначение |
|---|---|---|
| `ui_root.gd` | `UiRoot` (CanvasLayer) | Стек окон: `open()`, `close_top()`, `toggle()`; пауза, курсор, фокус |
| `ui_screen.gd` | `UiScreen` (Control) | Основа окна: `initial_focus`, сигнал `close_requested` |
| `fps_counter.gd`, `fps_counter.tscn` | `FpsCounter` (Label) | Кадры в секунду, в том числе на паузе |

Другие аддоны не нужны.

## Настройка

1. Скопируйте эту папку в `res://addons/iso_orbit/ui_screens/`.
2. Добавьте в главную сцену `CanvasLayer` с `ui_root.gd`. Он работает и тогда, когда игра на паузе.
3. Сделайте каждое окно сценой, корень которой наследует `UiScreen`. Окно никогда не закрывает себя само: оно
   вызывает `request_close()`, и его закрывает `UiRoot`.
4. Открывайте окна через `UiRoot.open(scene)`. Чтобы открывать окно по клавише, задайте его сцену в
   `settings_screen` и добавьте действие ввода `toggle_settings` (или задайте `settings_action`). Esc — это
   встроенное действие `ui_cancel`.
5. По желанию: добавьте `fps_counter.tscn` в свой HUD.

Внешний вид задаёт тема проекта; `FpsCounter` использует вариацию типа темы `FpsCounter`.
