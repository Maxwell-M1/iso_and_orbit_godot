# Окна интерфейса

[← Оглавление документации (репозиторий шаблона)](../../../docs/ru/index.md)

> Это перевод [английского оригинала](README.md). При расхождениях верен оригинал.

Окна поверх игры в виде стека: открывайте одно поверх другого, закрывайте верхнее по Esc; пока открыто хоть одно
окно, игра стоит на паузе и курсор мыши виден; фокус клавиатуры переходит в окно и возвращается обратно, когда окно
закрывается. Также есть счётчик FPS, работающий во время паузы, и названия назначенных действиям клавиш для
текстов на экране.

Часть Iso & Orbit — шаблона камеры и контроллера персонажа для Godot 4.7. Лицензия MIT (см. `LICENSE`).

## Состав

| Файл | Класс | Назначение |
|---|---|---|
| `ui_root.gd` | `UiRoot` (CanvasLayer) | Стек окон: `open()`, `close_top()`, `toggle()`; пауза, курсор, фокус |
| `ui_screen.gd` | `UiScreen` (Control) | Основа окна: `initial_focus`, сигнал `close_requested` |
| `fps_counter.gd`, `fps_counter.tscn` | `FpsCounter` (Label) | Кадры в секунду, в том числе на паузе |
| `input_names.gd` | `InputNames` (RefCounted, статический) | Клавиша или кнопка мыши для действия с учётом раскладки игрока и перевода: `of_action()`, `of_event()`; `format()` подставляет названия в текст по токенам вроде `{sprint}` |
| `action_texts.gd` | `ActionTexts` (Node) | Подставляет токены в тексты элементов управления под родителем, повторно при смене языка и вызове `refresh()` |

Другие аддоны не нужны.

## Настройка

1. Скопируйте эту папку в `res://addons/iso_orbit/ui_screens/`.
2. Добавьте в главную сцену `CanvasLayer` с `ui_root.gd`. Он работает и тогда, когда игра на паузе.
3. Сделайте каждое окно сценой, корень которой наследует `UiScreen`. Окно никогда не закрывает себя само: оно
   вызывает `request_close()`, и его закрывает `UiRoot`.
4. Открывайте окна через `UiRoot.open(scene)`. Чтобы открывать окно по клавише, задайте его сцену в
   `settings_screen` и добавьте действие ввода `toggle_settings` (или задайте `settings_action`). Без действия
   `UiRoot` сообщит об этом один раз при запуске, а клавиша не сработает. Esc — встроенное действие `ui_cancel`.
5. По желанию: добавьте `fps_counter.tscn` в свой HUD.
6. По желанию используйте в текстах токены действий, например `{jump} — jump`, и добавьте `ActionTexts` в сцену:
   он обслуживает элементы под своим родителем. После смены клавиш вызовите
   `get_tree().call_group(ActionTexts.GROUP, &"refresh")`. Элементы, которые собирают свой текст сами, могут
   реализовать `refresh()` и войти в ту же группу. Чтобы названия кнопок мыши, «Space» и неназначенных действий
   переводились, добавьте в переводы строки из `InputNames.get_mouse_names()`, «Space», `InputNames.UNBOUND`,
   `InputNames.LEFT_KEY` и `InputNames.RIGHT_KEY`. В двух последних сохраните `%s` для имени клавиши.

`UiRoot` ставит на паузу только работающую игру и снимает только собственную паузу. Если до открытия окна игра
уже стояла на паузе (например, при смене уровня), она остаётся под управлением того, кто поставил её. Если тот
снимет паузу, игра пойдёт за открытым окном.

Внешний вид задаёт тема проекта; `FpsCounter` использует вариацию типа темы `FpsCounter`.
